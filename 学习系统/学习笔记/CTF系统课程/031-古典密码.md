# 古典密码

## 凯撒密码

加密方法：明文中的所有字母都在字母表上向后（或向前）按照一个固定数目进行偏移后被替换成密文

例如：

原文：abcdef

偏移量：2

偏移量| 对比| 明文| | | | |   
---|---|---|---|---|---|---|---  
2| 偏移前| a| b| c| d| e| f  
| 偏移后| c| d| e| f| g| h  
  
* * *
    
    
    from string import ascii_lowercase as alphabet
    # alphabet: 'abcdefghijklmnopqrstuvwxyz'
    
    itoc = lambda i: alphabet[i]
    ctoi = lambda c: alphabet.index(c)
    
    def Caesar_enc(plaintext, k):
        ciphertext = ''
        for ch in plaintext:
            if ch not in alphabet:  # 修正：应该是 not in
                ciphertext += ch    # 非字母字符原样保留
                continue
            ciphertext += itoc((ctoi(ch) + k) % len(alphabet))
        return ciphertext
    
    def Caesar_dec(ciphertext, k):
        plaintext = ''
        for ch in ciphertext:
            if ch not in alphabet:  # 修正：应该是 not in
                plaintext += ch     # 非字母字符原样保留
                continue
            plaintext += itoc((ctoi(ch) - k) % len(alphabet))  # 修正：这行必须在循环内！
        return plaintext

#### 暴力穷举法：

凯撒密码使用的偏移量是有限的，使用26个字母的英文，他的偏移量最多就是25（偏移量26等同于偏移量0，即明文；偏移量超过26，等同于偏移量1-25）。因此可以通过穷举法，列出所有可能的偏移量解密后的结果，找到有意义的解密结果，即可破解该密码。

#### 字频分析法：

由于加密前后字频不变，密文中出现次数最多的字母，一定对应着正常英文文本中出现次数最多的字母e，从而可以确定偏移量，进行解密。

例题：oknqdbqmoq
    
    
    # 题目：oknqdbqmoq
    # 有点像被加密的flag，尝试使用凯撒密码破解
    
    from string import ascii_lowercase
    ciphertext = "oknqdbqmoq"
    
    itoa = lambda i: ascii_lowercase[i]
    ctoi = lambda a: ascii_lowercase.index(a)
    
    for k in range(26):
        decrypted = ''
        for c in ciphertext:
            if c in ascii_lowercase:
                decrypted += itoa((ctoi(c) -k) % 26)
            else:
                decrypted += c
        print(k, decrypted)

### 简单替换密码

#### 暴力穷举法：

需要穷举出所有可能的替换表，根据排列组合。替换表一共会有26*25*...*2*1=26！约等于2*88.4种可能，无法做到。

#### 字频分析法：

当密文长度足够大的情况下，可以先分析密文中每个字母出现的频率做比较。例如在英文中，正常明文中字母 E 和 T 出现的频率特别高，因此密文中出现的频率最高的字母很大概率对应的就是明文字母 E 或 T。再结合单词拼写和语境，即可逐步恢复出明文。

注：可以使用 collections.Counter() 进行频率分析

###  维吉尼亚密码

维吉尼亚密码（vigenere cipher）是在单一凯撒密码的基础上扩展出的多表代换密码，根据密钥（当密钥长度小于明文长度时可以循环使用）来决定用哪一行的密表来进行替换，以此来对抗字频统计。

例如：

明文：the rain in spain stays mainly in thi plain.

keyword：flamingo

| 明文  
---|---  
P| theraini| nspainst| aysmainl| yinthepl| ain  
K| flamingo| flamingo| flamingo| flamingo| flamingo  
C| yesdivtw| sdpmqays| fjsyivtz| dtnfprvz| ftn  
密文| yesdivtwsdpmqaysfjsyivtzdtnfprvzftn  
  
### 维吉尼亚密码的破解分为两步：

#### 1、确定密钥长度

    * 卡希斯基实验：寻找密文序列种重复的片段，列出重复的片段之间相隔的距离，那么密钥长度很大概率能够整除这些距离。
    * 重合指数法：根据密钥长度分类，每一组的字频分布应该跟英文文本的字频分布是吻合的。

#### 2、恢复密钥

确定完密钥长度后，维吉尼亚密码的每一组可被视作为一个简单的凯撒密码，根据字频分析求出偏移量即可。
    
    
    alphabet = 'abcdefghijklmnopqrstuvwxyz'
    
    
    def ctoi(char):
        """字符转索引 (a->0, b->1, ..., z->25)"""
        return ord(char.lower()) - ord('a')
    
    
    def itoc(index):
        """索引转字符 (0->a, 1->b, ..., 25->z)"""
        return chr((index % 26) + ord('a'))
    
    
    
    def Vigenere_enc(plaintext, keyword):
        ciphertext = ''
        i = 0
        for ch in plaintext.lower():
            if ch not in alphabet:
                continue
            shift = ctoi(keyword[i%len(keyword)])
            ciphertext += itoc((ctoi(ch) + shift) % len(alphabet))
            i += 1
        return ciphertext
    
    def Vigenere_dec(ciphertext, keyword):
        plaintext = ''
        i = 0
        for ch in ciphertext.lower():
            if ch not in alphabet:
                continue
            shift = ctoi (keyword[i%len(keyword)])
            plaintext += itoc((ctoi(ch) - shift) % len(alphabet))
            i += 1
        return plaintext

        print(f"密钥：")

        print(f"加密结果：")
    
        decrypted = Vigenere_dec(encrypted, keyword)
        print(f"解密结果：")

### 栅栏密码（Rail Fence Cipher）

加密方法：将明文分为 N 行（"栏"），再按列的顺序依次从每行中选出一个字母连起来，形成一段无意义的密文。

例题：

明文：Will invade Kentucky on October the eighth# signal is Frozen chicken' #

栏位：2

密文：WI LI NV AD EK EN TU CY NO CO OT EB HR TI EH GI NT LS GO FA ES CR IZ EN HC KI CN

**栅栏密码的栏数较小，即密钥空间很小，可以采取暴力破解的方式**
    
    
    #!/usr/bin/env python3
    # Rail Fence Cipher - Symbol Filtering Version
    
    def clean_text(text):
        """移除所有非字母字符"""
        return ''.join(c for c in text.upper() if c.isalpha())  # 修复：添加 in
    
    def rail_encrypt(plaintext, rails):
        """栅栏加密（自动过滤符号）"""
        clean_text_value = clean_text(plaintext)  # 重命名避免冲突
        
        print(f"Cleaned text: ")
        print(f"Length:  characters")
        
        rail_data = [[] for _ in range(rails)]
        for i, char in enumerate(clean_text_value):
            rail_index = i % rails
            rail_data[rail_index].append(char)
        
        # 显示栅栏排列
        print(f"\nRail arrangement ( rails):")
        for i, rail in enumerate(rail_data):
            print(f"Rail : ")
        
        ciphertext = ''
        for rail in rail_data:
            ciphertext += ''.join(rail)
        
        return ciphertext
    
    def rail_decrypt(ciphertext, rails):
        """栅栏解密"""
        length = len(ciphertext)
        plain = [''] * length
        idx = 0
        
        for rail in range(rails):
            for pos in range(rail, length, rails):
                if idx < length:
                    plain[pos] = ciphertext[idx]
                    idx += 1
        
        return ''.join(plain)
    
    def crack_rail(cipher):
        """暴力破解栅栏密码"""
        L = len(cipher)
        possible_rails = [i for i in range(2, L) if L % i == 0]
        
        print(f"Ciphertext: ")
        print(f"Length: , Possible rails: ")
        print("-" * 50)
        
        for r in possible_rails:
            plaintext = rail_decrypt(cipher, r)
            
            # 英文检测
            common_words = ['THE', 'AND', 'YOU', 'THAT', 'WITH', 'HAVE', 'THIS', 'WILL']
            if any(word in plaintext for word in common_words):
                print(f"🎯 FOUND: rails= -> ")
                return r, plaintext
            print(f"rails=: ")
        
        return None, None
    
    # 测试您的例子
    if __name__ == "__main__":
        print("🚀 Rail Fence Cipher - Symbol Filtering Demo")
        print("=" * 60)
        
        # 您的明文（包含符号）
        original_text = "Will invade Kentucky on October the eighth# signal is Frozen chicken' #"

        cleaned = clean_text(original_text)
        print(f"After removing symbols: ")
        
        print("\n" + "=" * 60)

        # 加密（自动过滤符号）
        rails = 2
        ciphertext = rail_encrypt(original_text, rails)
        print(f"\nFinal ciphertext: ")

        # 验证

        print(f"Decryption correct: ")

        print("BRUTE FORCE DEMO:")

            print(f"✅ Decrypted: ")
