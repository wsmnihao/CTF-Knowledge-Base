# 概述
	暴力破解是一种通过自动化工具和预设密码字典，在认证接口上不断尝试海量用户名与密码组合，直至猜中正确凭据的攻击手段。一个系统是否存在暴力破解漏洞，并非绝对，而是取决于其认证安全策略的强弱——若系统未采用强密码策略、验证码、登录失败限制或多因素认证等措施，其被暴力破解的可能性就相对较高。

# 基于token的验证
![[Pasted image 20260616113055.png]]

**抓包

	Token本身无法"爆破"，它只是随请求变化的动态参数。你真正爆破的是用户名和密码，同时让Token自动跟随每次响应更新

![[Pasted image 20260618084937.png]]

	攻击模式选择第三个，pitchfork攻击。

	第一个密码字段的payload选择简单列表，放入爆破字典
	注意：
**已知用户名 → 只需爆破密码字段 + Token跟随更新；用户名未知 → 需要同时爆破用户名字段，Token仍跟随更新**

![[Pasted image 20260618085042.png]]


	第二个token字段的payload模式选择为递归提取，并将请求体中的token值复制粘贴到首次请求初始payload，粘贴到里面

![[Pasted image 20260618085253.png]]

	点击设置，找到检索-提取选项，点击添加

**注：
1、勾选从响应包中提取以下项目
2、点击添加
3、点击重新获取响应
4、在下面的搜索框中输入value或者token，有token值即可
5、双击选中
6、选中token的值之后，这一步才会显示
7、ok！！！
![[Pasted image 20260618090113.png]]


	选择重定向，选择总是

	点击资源池
**注：
1、选择资源池
2、新建资源池
3、勾选最大并发请求数，也就是线程数
4、填1，每请求一次自动生成一个token
