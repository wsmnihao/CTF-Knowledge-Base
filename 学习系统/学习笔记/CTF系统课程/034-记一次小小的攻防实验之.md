# 记一次小小的攻防实验之

# 前言

本文记录了一次完整的红队基础设施搭建过程，核心目标是构建一个**安全、高效、可审计** 的指挥中心。在真实的攻防对抗中，稳固的基础设施往往决定了作战的成败。通过本次实践，我们不仅搭建了一个堡垒机，更建立了一套完整的攻防作战体系。

### **🔍****本次搭建的核心价值**

  * **统一入口** ：收敛攻击面，集中安全管理
  * **态势感知** ：实时掌握所有系统状态
  * **审计追溯** ：记录所有操作行为
  * **快速响应** ：建立标准化应急流程

**注意：本篇笔记的所有操作搭建完成之后，在虚拟机拍个快照，保存下来，假设最后一层防御，堡垒机挂掉之后，可以迅速建立起来新的指挥阵地，包括其他系统都拍个快照。**

### 系统安全加固
    
    
    sudo apt update && sudo apt upgrade -y		#更新系统，先做这个
    
    #之后翻到最底下查看工具简介
    # 安装堡垒机完整工具集，一行一行执行，不要复制后面的注释信息，安装完一个组的工具之后再安装下一个组的
    
    sudo apt install -y ufw fail2ban auditd lynis          # 安全防护组
    sudo apt install -y htop nethogs nmon tree             # 监控诊断组  
    sudo apt install -y nmap net-tools tcpdump curl wget git    # 网络工具组
    sudo apt install -y tmux screen jq python3 python3-pip # 核心组件
      
    
    
    
    #以下是每个工具的介绍
      #安全防护组
        ufw 				#防火墙
        fail2ban		#SSH放爆破
        auditd			#系统审计
        lynis				#安全扫描
    
      
      #监控诊断组
        htop				#进程监控
        nethogs			#网络流量
        nmon				#性能分析
        tree				#目录结构
    
    
      #网络工具组
        net-tools 	#网络诊断命令
        tcpdump			#抓包分析
        curl				#HTTP客户端
        wget				#文件下载
        git					#版本控制
    
    
      #核心工具组
        tmux				#终端多路复用器
        screen			#终端会话管理器
        jq					#JSON处理器
        python3			#python解释器
        python3-pip #包管理器
    
    
        
    
    #建议执行的方式：
    # 1. 先执行系统更新（单独执行，观察有无错误）
    sudo apt update && sudo apt upgrade -y
    
    # 2. 再执行工具安装（确认更新成功后）
    sudo apt install -y \
        ufw fail2ban auditd lynis \
        htop nethogs nmon tree \
        net-tools tcpdump curl wget git

#### 激活防火墙

##### 启用防火墙
    
    
    # 启用UFW防火墙
    sudo ufw enable
    
    # 设置默认策略
    sudo ufw default deny incoming		#默认拒绝所有入站连接，确保安全性
    sudo ufw default allow outgoing		#默认允许所有出站连接，堡垒机需要访问攻击机（kali）和蜜罐
    
    # 允许SSH连接，以防被对方扫描到攻击堡垒机，造成干扰！！！
    sudo ufw allow ssh
    sudo ufw allow 22
    sudo ufw status numbered
    
    # 查看最终状态
    sudo ufw status verbose
