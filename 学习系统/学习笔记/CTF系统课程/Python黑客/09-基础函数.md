### 概览
#### 作用
==代码重用：==
	通过定义函数，可以避免写重复的代码。当需要在程序的不同部分执行相同的操作时，可以调用同一个函数。
==模块化：==
	函数允许将程序分解成多个小模块，每个模块负责完成一个具体的功能，便于管理和维护。
==抽象：==
	使用函数可以将复杂的逻辑隐藏在函数内部，对外只暴露简单的接口，使得代码更加简洁易懂。
==调试简化：==
	当程序出现问题时，如果问题出在一个函数中，只需检查这个函数，而不必检查整个程序。
==可读性增强：==
	好的函数命名可以让人快速理解代码的功能，提高代码的可读性。
### 函数的构成

| 构成部分   | 描述                    | 是否必须 |
| ------ | --------------------- | ---- |
| 函数名    | 用于标识函数的唯一名称，方便调用      | 是    |
| 参数（形参） | 函数执行时可以接收的外部数据        | 否    |
| 函数体    | 包含一些列语句，用于定义函数应该执行的操作 | 是    |
| 返回值    | 函数执行完成后返回的结构          | 否    |
### 函数的参数类型

| 参数类型  | 描述                                  |
| ----- | ----------------------------------- |
| 必须参数  | 函数调用时必须按照定义的顺序传递的参数                 |
| 默认参数值 | 定义函数时可以给参数这是一个默认值，调用时如果不传该参数，则使用默认值 |
| 可变长参数 | 使用 * 号声明，可以接受任意数量的参数                |
| 字典参数  | 使用 ** 声明，可以接受任意数量的关键字参数             |
```python
# 1、无参数，无返回函数

def say_hello():

    print("Hello,Workd!")  

# 调用函数

say_hello()

  
  

# 2、有参数，无返回值

def greet_person(name):

    print(f"Hello,{name}!")

# 调用函数

greet_person("Alice")

  

# 3、有参数，有返回值

def caiculate_area(radius):

    area  = 3.14 * radius * radius

    return area

# 调用函数并接受返回值

area = caiculate_area(5)

print(f"The area of the circle is: {area}")

  

# 4、直接将函数名进行赋值或输出

def get_greeting():

    return "Hello, Python!"

# 调用这个get_greeting函数，并将返回值存储在变量greeting中

# 将函数名赋值给变量

greeting_message = get_greeting

print(greeting_message())  # 输出: Hello, Python!

# 输出函数名

print(greeting_message())  # 输出: Hello, Python!
```
