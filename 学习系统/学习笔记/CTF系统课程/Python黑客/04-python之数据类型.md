**常用类型
入门阶段，主要接触这三类

| 类型     | 描述       | 说明                   |
| ------ | -------- | -------------------- |
| string | 字符串类型    | 用引号括起来的数据都是字符串       |
| int    | 整形（有符号）  | 数字类型，存放整数，入-1，10，0等  |
| float  | 浮点型（有符号） | 存放小数，入-1.2，3.3，6.66等 |

**type()语句

我们如何通过type()语句来得到数据的类型呢？
==语法：==
```python
type(被查看类型的数据)
```

type()具体的使用方式
**1、在print语句中，直接输出类型信息：
![[Pasted image 20260721160442.png]]

代码示例
```python
print(type("你好呀，我是pycharm"))  
print(type(666))  
print(type(13.14))
```



2、同时也可以存储变量里面的内容
如下所示
![[Pasted image 20260721160728.png]]****

代码示例
```python
name = "张三"  
name_type = type(name)  
print(name_type)
```
