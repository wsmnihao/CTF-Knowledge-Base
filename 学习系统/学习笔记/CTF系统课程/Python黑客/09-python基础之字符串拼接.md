### 字符串拼接
如下所示：
```python
# 字符串字面量之间的拼接  
print("学习python" + "实现自动化流程")  
  
# 字符串字面量和字符串变量的拼接  
name = "张三"  
address = "中国电信"  
tel = 4000000001  
print("我叫：" + name + "我住在：" + address + "我的电话是：" ,tel)
```

注意：这里用+号将tel加起来会包类型错误的，可以用逗号，中间会有个空格，后续的学习会可以让大部分数据类型的变量都能用+拼接
