### 条件语句

| 条件语句   | 描述                   | 语法                  |
| ------ | -------------------- | ------------------- |
| if语句   | 检查条件是否为真，如果为真，则执行代码块 | if condition:<内容>   |
| elif   | 如果第一个条件为假，则检查第二个条件   | elif condition:<内容> |
| else语句 | 如果所有条件都为假，则执行这个代码块   | else:<内容>           |
```python
# if语句

x = 10

if x > 5:

    print("x大于5")

  
  

age = 18

if age >= 18:

    print("你是成年人")

  
  

# elif语句

x = 10

if x > 10:

    print("x大于10")

elif x == 10:

    print("x等于10")

  
  
  

grade = "A"

if grade == "A":

    print("Excellent")

elif grade == "B":

    print("Good")

  
  
  

# else语句

x =3

if x > 10:

    print("x等于10")

else:

    print("x不等于10")

  
  
  

# 综合示例

game = "王者荣耀"

if game == "英雄联盟":

    print("你在玩英雄联盟，偷着练手速去了吧")

elif game == "无畏契约":

    print("你在打瓦！！！你个瓦粉")

else:

    print("你在玩王者！！！背着我偷着上分！！！")
```
