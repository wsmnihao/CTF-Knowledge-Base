
### 字符串
```python
#定义字符串 赋值内容  
string_text = "Hello World!!!"  
  
##字符串切片  
#取下标，值为l  
print(string_text[3])  
  
# 字符串切片操作，左闭右开，值为Hello  
print(string_text[0:5])  
  
#从第二个开始到最后，但更像是截断欸  
print(string_text[1:])  
  
#从最开始到截至数字前，同上。  
print(string_text[:7])  
  
#取最后一个，-1为最后次字符串的最后一位，-2开始是反着数  
print(string_text[-1])  
  
#从第二个开始取到倒数第二个之前  
print(string_text[1:-2])  
  
#设置步长为2(感觉像是中间截取欸)  
print(string_text[0:5:2])  
  
#输出结果  
print(string_text)
```
### 布尔
```python
#定义布尔值  
is_python_cool = False  
  
is_gravity_fake = True  
  
  
#增：逻辑运算组合  
is_python_cool_and_gravity_fake = is_python_cool and is_gravity_fake  
print(is_python_cool_and_gravity_fake)  
  
#删：布尔值通常不单独删除，而是作为条件判断的一部分  
#改：通过逻辑运算改变布尔值  
is_python_cool = not is_python_cool  
#查：打印布尔值  
print(is_python_cool)
```
### 列表
```python
#定义列表   
fruits = ["apple","banana","cherry","orange","grape"]  
  
#增加：添加元素  
fruits.append("kiwi")  
  
#删除：删除元素  
fruits.remove("banana")  
  
#改：修改元素  
fruits[0] = "grapefruits"  
  
#查：访问元素  
first_fruit = fruits[0]  
  
#列表切片  
#获取从索引1开始到索引4（不包括索引4）的元素  
slice_fruits1 = fruits[1:4]  
  
#获取从索引0开始到索引-1（包括索引-1）的元素  
slice_fruits2 = fruits[:-1]  
  
#获取从索引3开始到列表末尾的元素  
slice_fruits3 = fruits[3:]  
  
#获取列表中所有的元素，但不包括最后一个  
slice_fruits4 = fruits[:-1]  
  
#输出结果  
  
print(fruits)  
print(first_fruit)  
print(slice_fruits1)  
print(slice_fruits2)  
print(slice_fruits3)  
print(slice_fruits4)  
  
#按照字典序对列表进行排序  
sorted_fruits = sorted(fruits)  
print(sorted_fruits)  
  
#排序，修改原数据，True也可以改成False，升序 
fruits.sort(reverse=True)  
print(fruits)  
##
```
### 字典
```python
#定义字典  
person = {"name":"Jhon","age":20}  
  
#增加：添加键值对  
person["gender"] = "male"  
print(person)  
  
#删除：删除键值对  
del person["gender"]  
print(person)  
  
#改：修改键值对  
person["age"] = 200  
print(person)  
  
#查：访问键值对  
name = person["name"]  
print(person)  
  
#获取字典的所有制  
keys = list(person.keys())  
print(keys)  
  
#获取字典的所有值  
values = list(person.values())  
print(values)
```
### 集合
```python
#定义集合

even_numbers = {0,2,4,6,8}  
  
#增加：添加元素  
odd_numbers.add(11)  
print(odd_numbers)  
  
#删除：删除元素  
odd_numbers.remove(5)  
print(odd_numbers)  
  
# #改：集合不能修改元素！！！但可以添加或者删除元素来改变集合！！！  
# odd_numbers[2] = 10  
  
#查：检查元素是否存在  
is_in_set = 12 in odd_numbers  
  
#输出结果  
print(odd_numbers)  
print(is_in_set)
```
