# 日志分析与流量分析

# 一、日志分析

web访问日志记录了web服务器接受处理请求及运行时错误等各种原始信息。通过度web日志进行的安全分析，不仅可以保住我们定位攻击者，还可以帮助我们还原攻击路径，找到网站存在的安全漏洞并进行修复。

## (一) 为什么要进行日志分析？

  * 故障诊断和排除
  * 系统性能优化
  * 安全监控和防范
  * 用户行为分析 

## (二) 日志的种类

AccessLog：用户访问日志

Exception：代码异常

SQL Log：数据库日志

第三方服务日志：调用第三方服务日志

CronLog：定时任务日志 

## (三) 日志级别

DEBUG：详细的信息

INFO：确认一切按预期运行

WARNING：意想不到的事情即将发生

ERROR：更严重的问题

CRITCAL：严重的错误

# 二、流量分析

## (一) 流量分析是什么

网络流量分析是指捕捉网络中流动的数据包，并通过查看包内部数据以及进行相关的协议、流量分析、统计等来发现网络运行过程中出现的问题。CTF比赛中，通常会对提供的一个包含流量数据的PCAP文件进行分析。

## (二) 为什么要进行流量分析

可以及时发现流量攻击

用户是通过什么关键词 进入网站

用户访问了哪些页面

了解用户访问规律

# 三、流量分析工具与类型

## (一) 工具介绍——wireshark

wireshark是一款网络封包分析软件。它可以用于捕获和分析计算机网络中传输的数据包，帮助用户深入了解网络通信和故障排除。wiresshark支持多种协议的解析，如Ethernet、TCP、UDP、HTTP等还饿可以查看和分析网络流量，检测网络问题、优化网络性能，并且对于网络安全方面的审计和监控也非常有用。
