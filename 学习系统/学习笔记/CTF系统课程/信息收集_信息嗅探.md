### 1\. 关键信息表

| 关键字      | 说明                                      |
| -------- | --------------------------------------- |
| site     | 指定域名                                    |
| inurl    | url中存在关键字的网页                            |
| intext   | 网页正文中的关键字（字符）                           |
| filetype | 指定文件类型                                  |
| intitle  | 网页标题中的关键字                               |
| link     | link:baidu.com即表示返回所有和baidu.com做了链接的url |
| info     | 查找指定站点的一些基本信息                           |
| cache    | 搜索Google（谷歌）里关于某些内容的缓存                  |
  
例：

site:edu.cn intext:后台管理

这些语法也可以用在其他浏览器里面，比如edge，Firefox等

## (八) 查找真实IP

### 1\. 目标服务器存在CDN

CDN为内容分发网络，主要解决因传输距离和不通运营商节点造成的网络速度性能低下的问题。说的简单点就是一组在不同运营商之间的对接节点上的高速缓存服务器，把用户经常访问的静态数据资源（例如静态的html、css、js图片等文件）直接缓存到节点服务器上，当用户再次请求时，会直接分发到离用户近的节点服务器上响应给用户，当用户有实际数据交互时才会从远程Web服务器上响应，这样可以大大提高网站的相应速度及用户体验。

所以如果渗透目标购买了CDN服务 ，可以直接ping目标的域名，但得到的并非真正的目标Web服务器，知识离我们最近的一台目标节点的CDN服务器，这就导致了我们没法直接得到目标的真实IP段范围。

### 3\. 绕过CDN寻找真实IP

确认目标域名有CDN以后，就需要绕过CDN来寻找真实的IP，方法如下：

#### 一、内部邮箱源：

一般的邮件系统都在内部，没有经过CDN的解析，通过目标网站用户注册或者RSS订阅功能，查看邮件寻找邮件头中的邮件服务器域名IP，ping这个邮件服务器的域名，就可以找到目标真实IP（必须是目标自己的邮件服务器，第三方的或公共邮件服务器是没有用滴）

#### 二、扫描网站测试文件：

如phpinfo、test等，从而找到目标的真实IP

#### 三、分站域名：

很多网站主站的访问量都会很大，所以主站都是挂CDN的，但是分站可能没有挂CDN，可以通过ping二级域名获取分站IP，可能会出现分站和主站不是同一个IP但在同一个C段下面的情况，从而能判断出目标的真实IP分段。

#### 四、国外访问：

国内的CDN往往只对国内用户的访问加速，国外就不一定了。可以通过国外代理网站来查询，可能会得到真实IP。

链接：

[https://asm.saas.broadcom.com/zh_cn/plans.php](https://asm.saas.broadcom.com/zh_cn/plans.php)

查询域名解析记录：

有的目标域名之前没有挂CDN，但是又解析记录，可以在网站上查询

链接：

[https://asm.saas.broadcom.com/zh_cn/plans.php](https://asm.saas.broadcom.com/zh_cn/plans.php)

验证获取的IP

如果目标是web，可以直接尝试IP访问，看返回结果是不是和访问域名返回的一样；或者加上端口号，逐个尝试访问。

注：IP访问会跟端口号，域名访问也是需要端口号的，只不过被省略了而已，比如：
