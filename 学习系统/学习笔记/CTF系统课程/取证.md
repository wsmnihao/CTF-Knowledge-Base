# 取证

# 一、取证概述

## (一) 简介

电子数据取证，即通过使用软件和工具，按照一些预先定义的程序全面地检查计算机系统，咦提取和保护有关犯罪的证据；通过收集计算机系统、网络系统以及其他电子设备中以数字化的信息编码形式出现的与案件有关的信息，对其进行保存、分析鉴定和出示，用来证明犯罪活动的过程。

## (二) 对象及应用

取证的对象包含：个人电脑、服务器、移动设备、存储介质、多媒体设备、嵌入式环境、区块链等。

CTF中的取证类题型包括：流量分析、内存镜像取证和磁盘镜像取证。

# 二、John the Ripper

## (一) 下载及安装

John the Ripper是一种暴力密码破解器，针对Windows、Linux和MacOS系统有对应的安装包，官网即可下载。在一些系统中已经内置对应安装包，可以直接在终端输入命令“sudo apt-get install john”，即可开始安装。安装完毕后，在终端输入命令“john”，若返回内容为john版本以及其命令参数，代表安装成功。

# 三、volatility

## (一) 下载及安装

volatility是一款个非常强大的内存取证工具，能够对导出的内存镜像进行分析，支持Windows、Linux和macOS等操作系统的取证。

下载链接：

[https://volatilityfoundation.org/](https://volatilityfoundation.org/)

cmder下载链接：

[https://github.com/cmderdev/cmder/releases](https://github.com/cmderdev/cmder/releases)

## (二) volatility的简单使用方法

命令参数

打开cmder。
    
    
    volatility.exe -f 镜像文件名称 imageinfo
    
    #示例：
    volatility.exe -f 1.vmem imageinfo  		#查看这个镜像的内存镜像信息
