# 一、十六进制编辑器-010Editor

## (一) 010 Editor的简介

010 Editor是一款专业的文本编辑器和十六进制编辑器，旨在快速轻松地编辑计算机上任何文件的内容。

## (二) 010 Editor的特点

010 Editor能够对二进制数据进行解析和分析，支持多种数据类型和结构的解析。

知识点切入：

1、压缩源文件数据区

2、压缩源文件目录区

3、压缩源文件目录结束标志

有无加密：

通常为全局方式位标记为2字节长度，第一字节数字为偶数表示无加密，例如：00，02，04等；为奇数表示有加密，例如：01，03，09等。

这里以加密时第一字节数字为奇数01为例说明zip文件的几种加密情况。

# 二、图片信息查看工具ExifTool

## (一) ExifTool常用命令

链接：

[https://sourceforge.net/projects/exiftool/files/exiftool-13.39_64.zip/download](https://sourceforge.net/projects/exiftool/files/exiftool-13.39_64.zip/download)

命令| 描述  
---|---  
exiftool test.jpg| 显示test.jpg的所有Exif信息  
exiftool -s -imageSize -ExposureTime test.jpg| 显示尺寸大小  
exiftool -common dir(dir是目录名)| 显示dir目录下所有可识别的文件的信息  
exiftool -l test1.jpg test2.jpg| 显示test1.jpg和test2.jpg的所有Exif信息  
exiftool -all=test.jpg| 删除test.jpg的所有信息  
exiftool -gps:all=test.jpg| 删除test.jpg的GPS信息  
exiftool -artist=me test.jpg| 将“me”写入test.jpg的艺术家标签  
  
# 三、图片隐写查看器StegSolve

## (一) LSB隐写

链接：

[https://github.com/Giotino/stegsolve/releases](https://github.com/Giotino/stegsolve/releases)

使用StegSolve的Data Extract（数据库提取）功能提取RGB数据信息

## (二) 单图异或

使用StegSolve的Stereogram Solver（立体图示）功能可以将图片与自身进行异或。

## (三) GIF分帧

使用StegSolve的Frame Browser（帧浏览器）功能可以展示gif图片的每一帧。

## (四) 双图分析

使用StegSolve的image combine（图像合并）功能可以对两张图片进行XOR、OR、AND、ADD等运算并显示运算的结果。

图片隐写术进阶

F5隐写

F5隐写是一种隐写容量，效率和安全性都非常高的图片隐写方法，此隐写方法支持bmp、gif和jpg格式的图片。

链接：

[https://github.com/matthewgao/F5-steganography](https://github.com/matthewgao/F5-steganography)

描述| 命令  
---|---  
加密| java Embed <img_file> <stego_file> -e <payload_file> [-p <password>]  
解密| java Extract <stego_file> [-p <password>]  
  
OutGuess隐写

OutGuess隐写会将隐写信息嵌入在量化后部位0或1的DCT系数最低有效位中，然后利用未被修改DCT系数对嵌入隐藏信息导致DCT系数直方图的改变做出纠正处理。

链接：

描述| 命令  
---|---  
加密| outguess [-k <password>] -d <payload_file> <img_file> <stego_file>  
解密| outguess [-k <password>] -r <stego_file> -t <out_file>
