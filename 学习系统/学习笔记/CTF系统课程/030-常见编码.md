# 常见编码

### 编码简介：

编码是信息按照预先规定的方法从一种形式转换为另一种形式的过程。

例子：

    * 文本文件（.txt）通过ASCII编码村春再计算机中
    * HTTP协议通过base64编码传输二进制数据

ASCII（美国信息交换标准代码）是基于拉丁字母的一套电脑编码系统，是最通用的的信息交换标准。

### 主要分为三个部分：

  * 不可打印的控制字符（0~31）
  * 可打印字符（32~127）
  * 扩展ASCII打印字符（128~255）

### 编码方式

  1. 先将待编码字符按照ASCII编码转换为8bit二进制形式
  2. 再将二进制序列切片组合，重组为若干个等长的二进制组
  3. 将每个二进制转化为十进制数字，并查表找到对应的可打印ASCII字符
  4. 重组若不足则补0，并将其编码为‘=’

根据分组长度的不通（4bit、5bit、6bit）可以分为三种base编码形式

  1. 4bit：base16编码，字母表为‘0123456789ABCDEF’
  2. 5bit：base32编码，字母表为‘ABCDEFGHIJKLMNOPQRSTUVWXYZ234567’
  3. 6bit：base64编码，字母表为‘ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/’
