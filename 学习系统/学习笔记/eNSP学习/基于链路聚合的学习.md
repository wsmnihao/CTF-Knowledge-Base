# 命令
```
#  手动
# 1、创建逻辑端口
int eth-trunk 10  # 这个编号与另外一侧的需要相同

# 2、配置手动链路聚合模式
mode manual load-balance 

# 3、配置方式和为IP模式
load-balance src-dts-ip

# 4、将物理端口加入逻辑端口
trunkport g 0/0/1 to 0/0/3

# 5、配置交换机模式
port link-type trunk
port trunk allow-pass vlan 10 20

```

```
# 自动配置
# 1、创建逻辑端口
interface eth-trunk xxx

# 2、配置自动模式
mode lacp-static

# 3、将物理端口加入逻辑端口
trunkport g 0/0/1 to 0/0/3

# 对打存活数量
max active-linknumber x

# 4、配置逻辑端口 
trunk
```
