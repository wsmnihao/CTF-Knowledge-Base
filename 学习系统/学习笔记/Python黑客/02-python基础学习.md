# 字面量
## 什么是字面量

在代码中，被写下来的固定的值，称之为字面量

**示例


# 注释
## 什么是注释

单行注释：
	以==#开头的，在#右边的==所有文字都是注释，可以充当说明，不被执行，略过这个直接执行后续的程序，起到辅助说明的。
![[Pasted image 20260721115056.png]]

多行注释：
	以一对三个引号引起来的（'''注释内容'''）来解释说明的一段代码的使用方法
![[Pasted image 20260721115258.png]]
