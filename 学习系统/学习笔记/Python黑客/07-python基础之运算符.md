### 复合赋值运算符
![[Pasted image 20260721170009.png]]

示例
```python
# 复合赋值运算符  
num = 1  
print(num)  
num += 1  # num = num + 1  
print(num)  
num -= 1  # num = num - 1  
print(num)  
num *= 4  # num = num * 4  
print(num)  
num /= 2  # num = num / 2  
print(num)  
num %= 2  # num = num % 2  
print(num)  
num **= 2 # num = num ** 2  
print(num)  
num //= 2 # num = num // 2  
print(num)

```
