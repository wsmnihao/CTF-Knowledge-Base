```

```

		firewall-cmd --add-port={80/tcp,8080/tcp}
		firewall-cmd --list-ports
```

```

# 三、华为防火墙
1、usg5300/usg6000v两者只有个登录需要账号密码什么的
	关闭提示弹窗
```
	undo in en
```
	或者将弹窗改为中文模式
```
	language-mode chinese
```
![[屏幕截图 2025-11-08 203443.png]]
	开启防火墙web图形化管理界面
```
	web-manager enable
```
![[屏幕截图 2025-11-08 203903.png]]
	将接口划入trust（信任区域）
```
	firewall zone trust
	add in g0/0/1
	add in g0/0/2
	dis this
```
![[屏幕截图 2025-11-08 211107.png]]
	将接口划入untrust（不可信区域）
```
	firewall zone untrust 
	add in g0/0/3
	dis this
```
![[屏幕截图 2025-11-08 211524.png]]
	建立trust和untrust区域间由高到低的转发策略（允许访问）
```
	policy interzone trust untrust outbound
	policy 1
	policy source 192.168.1.0 0.0.0.255
	action permit
	q
	
	policy 2
	policy source 192.168.2.0 0.0.0.255
	action permit
	q
	
```
![[屏幕截图 2025-11-08 213211.png]]
	建立untrust和trust区域间的访问策略（不允许访问）
```
	policy interzone untrust trust outbound
	policy 3
	policy source 192.168.3.0 0.0.0.255
	action deny
	q
```
![[屏幕截图 2025-11-08 214103.png]]
	效果展示：
	1和2能互相访问，也能访问3，但是3不能访问1和2
