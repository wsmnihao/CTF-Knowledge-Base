## 🎯 核心心法
- **正向扫描**（-sS/-sT）容易被现代防火墙拦截并记录真实 IP。
- **高级扫描**的核心是利用底层协议的“非正常操作”（异常标志位、分片、伪造 IP），来**探测防火墙规则**或**隐藏攻击者真实位置**。

---

## 🚪 一、 异常标志位扫描 (绕过无状态防火墙)

这三种扫描专门用来对付“只看 SYN 标志”的老式防火墙。**反直觉逻辑：没有回应说明端口开放，回 RST 说明端口关闭。**

| 扫描类型 | 参数 | 点亮的标志位 | 实战场景与限制 |
| :--- | :--- | :--- | :--- |
| **Null (空) 扫描** | `-sN` | **0 个**（全 0） | 绕过简单防火墙，但现代有状态防火墙全拦。 |
| **FIN 扫描** | `-sF` | **1 个** (FIN) | 同上。 |
| **Xmas (圣诞) 扫描** | `-sX` | **3 个** (FIN, PSH, URG) | 标志位全亮，像圣诞树。同上。 |
| **Maimon 扫描** | `-sM` | **2 个** (FIN, ACK) | 针对极老的 BSD 系统（现代系统全回 RST，**已淘汰**）。 |

## 🛡️ 二、 防火墙规则探测 (画地图专用)

**注意：ACK 和 Window 扫描不能用来找开放的服务！它们只用来探测“防火墙有没有放行这个端口”。**

| 扫描类型 | 参数 | 特点 | 实战意义 |
| :--- | :--- | :--- | :--- |
| **ACK 扫描** | `-sA` | 只设 ACK 标志位。防火墙放行的显示 `unfiltered`，拦截的显示 `filtered`。 | 摸清防火墙的白名单/黑名单策略。 |
| **Window 扫描** | `-sW` | 类似 ACK，但检查 RST 包里的 Window 窗口大小。 | 针对特定系统，能通过窗口大小判断端口是否开放。 |
| **自定义扫描** | `--scanflags` | 自己拼装标志位，如 `--scanflags RSTSYNFIN`。 | 用于测试 IDS 的特殊拦截规则。 |

## 🥷 三、 隐匿与欺骗技术 (防止溯源)

### 1. 伪造源 IP (`-S`) 和 MAC (`--spoof-mac`)
- `sudo nmap -S 10.10.10.11 <目标IP>`
- **致命缺点**：目标把回包发给了假 IP，你收不到，除非你能截获中间流量。通常配合 `-e` 指定网卡和 `-Pn` 跳过主机发现使用。

### 2. 诱饵扫描 (`-D` 影分身之术)
- `sudo nmap -D 10.10.0.1,RND,ME <目标IP>`
- **原理**：拉上一堆假 IP（`RND` 随机生成，或填真实 IP）和你自己的真实 IP（`ME`）一起去扫。目标日志里会出现一堆 IP，让防守方无从下手封禁。
- **实战注意**：最多加 3-5 个，加太多容易触发并发阈值告警。不要用 `RND` 填真实公网大厂 IP，容易误伤。

### 3. 数据包分片 (`-f` 和 `--mtu`)
- **原理**：把数据切碎了发，骗过只检查完整包的老式 IDS。
- `-f`：切成 8 字节碎片。
- `-ff`：切成 16 字节碎片。
- `--mtu <数字>`：自定义碎片大小（必须是 8 的倍数）。
- `--data-length 100`：反向操作，故意往包里塞垃圾数据把包撑大，伪装成正常业务包。

### 4. 终极隐匿：僵尸扫描 (`-sI`)
- `sudo nmap -sI ZOMBIE_IP <目标IP>`
- **原理**：找一台闲置的、IP ID 递增的老机器当僵尸。伪造僵尸的 IP 去扫目标，通过观察僵尸的 IP ID 增量来判断目标端口是否开放。
- **条件**：僵尸机必须“闲”，且现代系统随机化 IP ID 导致此招几乎绝迹。

## 📊 Nmap 高级参数速查表 (实战小抄)

| 参数 | 说明 |
| :--- | :--- |
| `--reason` | **排错神器**。显示 Nmap 为什么把这个端口判定为 `open` 或 `closed`（如 `syn-ack`, `reset`）。 |
| `-v` / `-vv` | 冗长模式，实时显示扫描进度和细节。 |
| `-d` / `-dd` | 调试模式，打印底层发包细节（屏幕会疯狂刷屏）。 |
