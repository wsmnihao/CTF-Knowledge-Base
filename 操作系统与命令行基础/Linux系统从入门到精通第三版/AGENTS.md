1. **基线 Ubuntu 24.04 LTS**，内核 6.x，systemd，apt/dpkg，AppArmor，nftables。

2. **不写过时技术**：ReiserFS、xinetd、dump/restore、SysV init、`/etc/init.d/`、`ifconfig`、`netstat` 主线、`apt-key`、`python`(无3)、`useradd` 不加 `-m`。详见 skill 的 `BANNED.md`。
3. **内容原创**，不转录、不近似改写任何已出版教材。原书与教学 PPT 只作结构参考。
4. **写全**，不给大纲、不给省略号占位。宁可拆两次交付。

- 5.1 `cp` 三个「不」+ 「目标是否已存在目录」这个最高频坑 + `-a` 里 `-d` 才是符号链接能保留的原因
- 5.2 `mv` 同 fs = `rename(2)` 瞬间原子 / 跨 fs = 复制+删除，**并讲清「正在被写入的文件会丢后续数据」的 inode 级原因**（fd 还开着但文件名没了）
- 5.3 `rm -f` 的字面含义、为何 `--preserve-root` 挡不住 `rm -rf /*` 和变量为空、**唯一的后悔药 `/proc/PID/fd` 抢救被删文件**（接第 4 章）
- 5.4 `mkdir -p` 幂等 / `rmdir` 拒绝删非空目录 / `rmdir -p` 删空目录树
- 5.5 `find -print` → `find -delete` 的**天然预演机制**
- 5.6 tar 五个常用写法 + `-C` + 关键的 `.` + `--exclude` + `--strip-components`；⚠️ 不可信 tar 解包的路径穿越风险
- 5.7 gzip/bzip2/xz 取舍表、**gzip 默认删原文件**、已压缩数据别再压
- 5.8 tar vs zip 对比（属性保留是分界线）
- 5.9 rsync 斜杠语义、`--delete` 为何是全书最危险单条命令、**干跑纪律**、`--backup-dir` 加固
- 5.10 `-mtime` 向下取整（`+7` 实际 8 天）、**`-exec {} +` 比 `{} \;` 快一到两个数量级**、与 xargs 的分工、`-print0`/`-0` 强制规则、`-prune -o` 表达例外
- 5.11 find（实时准确但慢）vs locate（快但可能过期），脚本用 find
- 实验：rsync 本地镜像，**故意演示 `--delete` 清空目标的全过程**并用 `--backup-dir` 兜底
