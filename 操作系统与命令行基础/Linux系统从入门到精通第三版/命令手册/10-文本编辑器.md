# 10 · 文本编辑器（vim / nano / 编辑器约定）

---

# 第一部分 · 编辑器约定

## EDITOR / VISUAL — 决定「哪个程序是编辑器」

很多工具不让你指定具体编辑器名，而是读环境变量：

| 变量 | 作用 | 优先级 |
|---|---|---|
| `SUDO_EDITOR` | `sudoedit` 用的编辑器 | sudo 时最高 |
| `VISUAL` | 交互式编辑器 | 高 |
| `EDITOR` | 非交互式编辑器 | 中 |

```bash
$ echo $EDITOR
$ echo $VISUAL
$ sudo update-alternatives --config editor   # 系统级改默认编辑器（Debian/Ubuntu）
$ select-editor                          # 同样作用

# 一次性指定
$ VISUAL=nano crontab -e

# git 用哪个编辑器
$ git config --global core.editor "vim"
$ git config --global core.editor "nano -w"

# 让所有程序都用 nano
$ export EDITOR=nano VISUAL=nano
```

⚠️ **只用 `EDITOR` 不用 `VISUAL` 的老程序会看不到 `VISUAL`**。两个都设更保险。

⚠️ **远程 SSH 上设成 `vi` 容易卡住**（因为 vi 可能是 vim.tiny，配置不熟）。新手设 `nano` 更安全。

---

## sudoedit — 安全地编辑 root 文件

```bash
sudoedit [选项]... 文件...
```

| 选项 | 作用 |
|---|---|
| `-u 用户` | 用另一个用户运行编辑器 |
| `-S` | 用 root 身份运行 `sudoedit` 本身（配合 `-u`） |

```bash
$ sudoedit /etc/hosts
$ sudoedit /etc/fstab /etc/hosts          # 一次改多个
$ sudoedit -u www-data /var/www/index.html
```

⚠️ **`sudoedit` 会把自己的进程降权到调用者**，再通过一小段提权部分写回。所以它**不需要你以 root 身份运行编辑器**，比 `sudo vim /etc/xxx` 安全得多（编辑器的 swap 文件和备份文件不会带 root 权限）。

⚠️ **`sudo vim /etc/xxx` 会在同目录留下 `.xxx.swp`（属主 root）**，下次用普通用户编辑会报错。**改系统文件优先用 `sudoedit`。**

⚠️ **`sudoedit` 会保持原文件的属主和权限**，这是它相对 `sudo cp + edit` 的另一个好处。

# 第二部分 · nano

## nano — 新手友好

```bash
nano [选项]... [文件]
```

| 选项 | 作用 |
|---|---|
| `-l` | **显示行号** |
| `-w` | **按行软换行**（不改变实际行） |
| `-n 行` | 指定显示的行号 |
| `+行` | 打开时跳到某行 |
| `+行,列` | 跳到行列 |
| `-c` | 显示光标位置（列） |
| `-i` | 自动缩进 |
| `-k` | 剪切时整行剪切 |
| `-b` | 只做备份（备份成 `~` 结尾） |
| `-m` | 不自动换行（默认就关） |
| `-t Tabs` | Tab 宽度 |
| `-d` | 不自动检查文件末尾换行 |
| `-x` | 关闭（十六进制）模式 |

```bash
$ nano /etc/hosts
$ nano -l -w config.yaml        # ⭐ 显示行号 + 软换行
$ nano +100 /var/log/syslog    # 打开跳到第 100 行
$ nano -ln file                 # 行号 + 列位置
```

**快捷键（`^` 表示 Ctrl，`M` 表示 Alt）**

| 操作 | 快捷键 |
|---|---|
| 保存 | `^O` |
| 退出 | `^X` |
| 另存为 | `^O` 后改文件名 |
| 查找 | `^W` |
| 继续查找 | `^K` |
| 替换 | `^\` |
| 剪切整行 | `^K` |
| 粘贴 | `^U` |
| 光标所在行 | `^C`（显示行列号） |
| 撤销 | `^U` |
| 保存并退出 | `^O` 然后 `Enter` |
| 退出不保存 | `^X` 然后 `N` |

⚠️ **`^X` 退出会问是否保存**，直接回车是「是」，`N` 是「不」。**不加 `-w` 时软换行的长行在保存后仍是一行**。

⚠️ **nano 底部快捷键提示会随屏幕宽度折叠成 `^X Exit`**，找不全就按 `^K`（帮助里能看全部）。

⚠️ **`^K` 在 nano 里是「剪切整行」，不是 vim 里的「查找下一个」**。两套肌肉记忆不要混。

⚠️ **粘贴带格式的文本前先备份**。编辑器不保证不破坏已有内容，重要文件改之前 `cp file file.bak`。

# 第三部分 · vim

## vim — 启动与基本用法

```bash
vim [选项]... [文件...]
```

| 选项 | 作用 |
|---|---|
| `-r 文件` | 打开崩溃后留下的 swap 文件恢复 |
| `-R` | **只读打开** |
| `-Z` | 只读打开（Linux 上的限制模式） |
| `-c 命令` | 打开后执行命令（`vim -c ':set nu' file`） |
| `+行` / `+{行}` | 打开跳到某行 |
| `-b` | 二进制模式 |
| `-o[跳数]` | 第一次打开时自动记命令（宏） |
| `-S 文件` | 打开后 source 一个文件 |
| `-u 配置文件` | 指定 vimrc（`NONE` 表示不读） |
| `-i viminfo` | viminfo 文件位置 |
| `-x` | 加密（不可靠） |
| `-p N` | 打开 N 个标签页 |
| `-M` | 关闭改写（不写 backup） |

```bash
$ vim /etc/hosts
$ vim -R /etc/passwd              # ⭐ 只读看系统文件
$ vim -c '/error/' file           # 打开直接跳到含 error 的行
$ vim +50 app.log                 # 跳到第 50 行
$ sudo vim -r /etc/hosts.swp      # 崩溃后恢复
```

⚠️ **看到 `E325: ATTENTION` 或 `Swap file already exists`** 说明有人在编辑，或上次崩溃留了 swap。用 `vim -r` 恢复，或删掉 `.swp`（确认没人真在编辑）。

⚠️ **`-R` 只读打开系统文件比先 `cp` 再改安全**。改成 `-w` 后另存回原处：

```bash
$ vim -R /etc/hosts
# 编辑完： :w! /etc/hosts    （强制写只读文件）
```

⚠️ **vim 本身不是编辑器，是 vi 的改进版**。Ubuntu 里 `vi` 可能指向 `vim.tiny`（功能少、没有语法高亮）。**要用就用 `vim`。**

## 三种模式

```
命令模式 (Normal)  ──i/o/a/R──▶  插入模式 (Insert)
     ▲                                │
     └────────── Esc ─────────────────┘
     
命令模式 ──: ──▶ 命令行模式 (Command-line)
命令模式 ──v/V/Ctrl-V ──▶ 可视模式 (Visual)
```

| 模式 | 进入方式 | 用途 |
|---|---|---|
| 命令模式 | 启动默认，`Esc` 回到 | 移动、删除、复制 |
| 插入模式 | `i` `a` `o` `O` `I` `A` `c` | 打字 |
| 命令行模式 | `:` `?` `/` | 保存、查找、设置 |
| 可视模式 | `v` `V` `Ctrl-V` | 选中操作 |

## 移动

| 命令 | 作用 |
|---|---|
| `h` `j` `k` `l` | 左下上右 |
| `H` `M` `L` | 屏幕首/中/尾行 |
| `w` / `W` | 下一个词 / 大写移动 |
| `b` / `B` | 上一个词 |
| `e` / `E` | 词尾 |
| `gg` / `G` | 文件开头 / 末尾 |
| `0` / `^` / `$` | 行首 / 行首非空白 / 行尾 |
| `3w` | 前进 3 个词 |
| `{` / `}` | 上/下一个段落 |
| `(` / `)` | 上/下一个句子 |
| `Ctrl-d` / `Ctrl-u` | 翻半屏 |
| `Ctrl-f` / `Ctrl-b` | 翻整屏 |
| `zz` / `zt` / `zb` | 当前行居中/置顶/置底 |
| `ma` | 设标记 a（最多 26 个，`'a` 跳回） |
| `` Ctrl-o `` | 跳回上一次位置 |

⚠️ **`j`/`k` 是下/上，`h`/`l` 是左/右**，这个方向来自「手放中心」的思路，**不是数学方向**。新手最容易搞混。

⚠️ **`G` 单独是跳到文件末尾**，带数字才是跳到某行（`50G`）。

⚠️ **`0` 是真正的行首**，不管前面有没有空格；`^` 跳到行首第一个非空白字符。

⚠️ **`gg` 要连按两次**，很多人以为是一下。

## 插入与编辑

| 命令 | 作用 |
|---|---|
| `i` | 在光标前插入 |
| `a` | 在光标后插入 |
| `I` | 行首第一个非空白处插入 |
| `A` | 行尾插入 |
| `o` | 下方新开一行并插入 |
| `O` | 上方新开一行并插入 |
| `c{motion}` | 删除并进入插入（`cw` 改词，`cc` 改行） |
| `r{字符}` | 替换一个字符 |
| `R` | 进入替换模式（覆盖式） |
| `J` | 与下一行合并 |
| `.` | **重复上次的修改** |
| `u` / `Ctrl-r` | 撤销 / 重做 |
| `Ctrl-u` | 撤销一行内的多次 |

```bash
# 插入模式里的键
Esc        # 回到命令模式
Ctrl-[     # 同 Esc（习惯 emacs 的用这个）
Ctrl-w     # 删前一个词
Ctrl-u     # 删到行首
Ctrl-k     # 删到行尾
Ctrl-h     # 退格
Ctrl-a/e  # 行首/行尾
Ctrl-o     # 临时回命令模式执行一个命令
```

⚠️ **`.` 重复修改是 vim 的灵魂**，但**只重复最后一次「修改类」操作**。移动光标不影响重复，`i` 插入的文字能用 `.` 复制，`.dd` 会连着删行。

⚠️ **粘贴后光标会跳到粘贴内容的末尾**，再用 `.` 可能重复错误的东西。粘贴完先 `Esc` 确认位置。

⚠️ **`Ctrl-r` 是重做，不是「删除行」**。vim 里删行是 `dd`。

## 删除、复制、粘贴

| 命令 | 作用 |
|---|---|
| `x` | 删一个字符 |
| `X` | 删光标前一个 |
| `dd` | 删行 / 剪切行 |
| `D` | 删到行尾 |
| `dw` | 删到下一个词首 |
| `d{motion}` | 按动作删 |
| `yy` | 复制行 |
| `y{motion}` | 按动作复制 |
| `p` / `P` | 粘贴到后面 / 前面 |
| `J` | 合并行 |

```bash
3dd       # 删 3 行
ddp       # 删一行马上粘回来（= 移动一行）
yyp       # 复制一行粘到下面（= 复制一行）
d/pattern\n     # 删到匹配 pattern 的地方
ciw      # ⭐ 改当前词（改变量名神器）
```

⚠️ **`dd` 在一行最后一个词后面按会删不到东西**（因为没内容了），结果不是「删除一行」。删整行时把光标放在行内任意非行尾位置更稳。

⚠️ **`p` 粘在光标后（下一位置）**，`P` 粘在光标前。**整行粘贴时区别很明显。**

⚠️ **粘贴整行时如果行内有缩进，会带出额外缩进**（因为 `p` 也算一行插入，触发 autoindent）。**配置 `set paste` 或用 `:set paste` 后粘贴。**

## 撤销与重复

| 命令 | 作用 |
|---|---|
| `u` | 撤销 |
| `Ctrl-r` | 重做 |
| `U` | 撤销当前行的所有改动 |
| `.` | 重复上次修改 |
| `g-` / `g+` | 早退/晚一步（撤销树） |

⚠️ **撤销不跨会话**。`u` 只能撤销本次打开后的修改，**关掉重开就恢复不了**，swap 文件恢复才行。

## 查找与替换

```bash
/pattern      # 向下查找
?pattern      # 向上查找
n / N         # 下一个 / 上一个匹配
* / #         # 查当前词的下一个 / 上一个出现
:%s/old/new/g  # ⭐ 全文替换
```

| 替换命令 | 说明 |
|---|---|
| `:%s/a/b/g` | 全文替换所有 |
| `:%s/a/b/gc` | **逐个确认（⭐ 最安全）** |
| `:%s/a/b/gi` | 忽略大小写 |
| `:%s/a/b/ge` | 没有匹配也不报错 |
| `:'<,'>s/a/b/g` | 只替换可视范围（按 `*` 选中后自动出现） |
| `:5,10s/a/b/g` | 替换 5–10 行 |
| `:%s/\(a\)\(b\)/\2\1/g` | 用 `\1` `\2` 引用分组 |

```bash
# 带正则的替换
:%s/192\.168\.1\./10.0.0./g
:%s/^\s*#\(.*\)/\1/g          # 去掉行首注释
:%s/foo/bar/gc                 # ⭐ 逐个确认
:%s/a/b/ge                    # 文件里没有也不报错

# 保存查找过的模式
:history /                   # 查过的内容
```

⚠️ **替换里 `.` `*` `[` 是正则元字符，要转义**。`s/a.b/b/` 里的 `.` 匹配任意字符，不只是字面点。**替换字面量字符串时用 `\V`（very nomagic）**：`:%s/\Vfoo.bar/foo.bar/g`。

⚠️ **`gc` 逐个确认时，`a` 全部替换，`q` 退出，`n` 跳过，`y` 当前替换**，大写 `A`/`Q`/`N`/`Y` 是反过来。

⚠️ **替换前先 `:set number` 确认范围**。`:%s` 是全文，`:s` 只作用当前行。

⚠️ **替换里用 `/` 要转义或换分隔符**：`s/a/b\/c/` 或 `s|a|b/c|`。

⚠️ **`:s///` 不带范围时只对当前行生效**，很多新手以为改了整个文件。

## 保存与退出

| 命令 | 作用 |
|---|---|
| `:w` | 保存 |
| `:w 文件` | 另存为 |
| `:w!` | 强制保存（只读文件/放弃修改） |
| `:wq` / `:x` | 保存退出（`:x` 只在有改动时存） |
| `:q` | 退出 |
| `:q!` | **不保存退出** |
| `:qa` | 全部退出 |
| `:e!` | 放弃改动重新载入文件 |
| `:w >> 文件` | 追加到文件 |
| `:set nobackup` | 关闭备份 |
| `:set nowritebackup` | 关闭 swap |

⚠️ **`:q` 在有未保存改动时会拒绝**，必须 `:q!` 或 `:wq`。**`:q!` 会丢弃所有改动，无法撤销。**

⚠️ **`:wq` 写的是所有内容，`:x` 只在有改动时写**。在脚本或自动化里 `:x` 避免无谓的 mtime 变化。

⚠️ **`:w` 只保存不退出**。改完 `:w` 然后 `:q` 分两步也行，但 `:wq` 一次搞定。

## 视窗与标签页

| 命令 | 作用 |
|---|---|
| `:split 文件` / `:sp` | 水平分屏 |
| `:vsplit` / `:vsp` | 垂直分屏 |
| `Ctrl-w h/j/k/l` | 在窗口间移动 |
| `Ctrl-w w` | 循环切换窗口 |
| `Ctrl-w q` | 关闭窗口 |
| `Ctrl-w =` | 所有窗口等高 |
| `:q` （多个窗口时） | 关闭当前窗口 |
| `:tabnew 文件` | 新标签页 |
| `:tabnext` / `Ctrl-w t` | 下一个标签 |
| `:tabonly` | 只留当前标签 |
| `:ls` | 列出所有窗口和标签 |

⚠️ **多窗口下 `:q` 是关窗口，不是退出 vim**。全关完才退出。

⚠️ **`Ctrl-w` 后要隔一下再按 `hjkl`**。按太快会被识别成 `Ctrl-w` + `hjkl` 之外的东西。

⚠️ **`:vsp` 垂直分屏才是「左右两栏」**（大部分人直觉相反，vim 里 `:sp` 是上下）。

## 寄存器与宏

| 命令 | 作用 |
|---|---|
| `"ayy` | 把行存进寄存器 a |
| `"ap` | 粘贴寄存器 a |
| `"0p` | 粘贴刚删除的内容 |
| `q{字母}` | 开始记录宏 |
| `q` | 停止记录 |
| `@{字母}` | 执行宏 |
| `@@` | 重复上次宏 |
| `:{范围}@{字母}` | 对范围执行宏 |

```bash
# 批量加行尾逗号
qa              # 开始记录到 a
A,              # 到行尾加逗号
q               # 停止
:j,$@a          # 从当前行到最后一行执行

# 不用宏也能做
:%s/$/,/
```

⚠️ **寄存器名 `a` 到 `z` 是有名字的，`0-9` 是自动的**。`"ayy` 后 `"0` 里还是原来那份。

⚠️ **`@a` 里的 `a` 要按成寄存器名，不是宏名**。宏用 `q` 记录的。

## 常用配置（:set）

| 配置 | 作用 |
|---|---|
| `:set number` / `nu` | 显示行号 |
| `:set relativenumber` / `rnu` | 相对行号 |
| `:set nonumber` / `nonu` | 关行号 |
| `:set ignorecase` / `ic` | 查找忽略大小写 |
| `:set smartcase` / `scs` | 有大写就区分大小写 |
| `:set incsearch` / `is` | 边输入边高亮匹配 |
| `:set hlsearch` / `hlsearch` | 高亮所有匹配 |
| `:set wrap` / `nowrap` | 自动换行显示 / 不换行 |
| `:set list` | 显示不可见字符（Tab、空格、行尾 `$`） |
| `:set expandtab` / `et` | Tab 转空格 |
| `:set tabstop=4` / `ts=4` | Tab 显示宽度 |
| `:set shiftwidth=4` / `sw=4` | 缩进宽度 |
| `:set softtabstop=4` / `sts=4` | 退格对齐缩进 |
| `:set autoindent` / `ai` | 自动缩进 |
| `:set smartindent` / `si` | 智能缩进 |
| `:set paste` | 粘贴模式（关闭自动缩进） |
| `:set indentkeys` | 配置 C 风格缩进 |
| `:set showmode` | 状态栏显示 `-- INSERT --` |
| `:set cursorline` | 高亮当前行 |
| `:set syntax on` | 语法高亮 |
| `:set filetype=sh` | 设置文件类型 |
| `:set encoding=utf-8` | 编码 |
| `:set nobackup` / `nowritebackup` | 关闭备份/swap |
| `:set undolevels=1000` | 撤销步数 |
| `:set mouse=a` | 启用鼠标 |
| `:set lazyredraw` | 大文件性能 |

```bash
# 常用的组合
:set nu
:set ic scs
:set list
:set et ts=4 sw=4 sts=4 ai
:set paste        # 粘贴前
:set nopaste      # 粘贴后

# 配置文件位置
$ ls -la ~/.vimrc ~/.vim/ ~/.config/vim/ 2>/dev/null
$ vim ~/.vimrc                     # 个人配置
$ sudo vim /etc/vim/vimrc          # 系统配置
$ vim /usr/share/vim/vimrc/colors/pablo.vim   # 看配色文件

# 查配置在哪生效
$ vim --startuptime
$ vim -Nu NONE -n -es -c 'set nu?' -c 'q!' file   # 不读 vimrc 测试
```

⚠️ **`:set` 只对当前会话生效**。要永久生效写进 `~/.vimrc`。

⚠️ **`expandtab` + `softtabstop=4` + `shiftwidth=4` + `tabstop=4` 是一组**，缺一个缩进就会不对齐。

⚠️ **`:set paste` 粘贴完要记得 `:set nopaste`**，否则之后的输入不会自动缩进。

⚠️ **`~/.vimrc` 写错会导致 vim 启动报错**。改完用 `vim -Nu ~/.vimrc -n -es -c q` 测试。

## vimdiff / diff

```bash
vimdiff 文件1 文件2              # ⭐ 比对两个文件
gvimdiff 文件1 文件2
vimdiff -r 目录1 目录2           # ⭐ 递归比对整个目录
```

**vimdiff 里的跳转**

| 命令 | 作用 |
|---|---|
| `]c` / `[c` | 下一个 / 上一个差异块 |
| `do` | 把当前文件的这一处**拉到**另一文件 |
| `dp` | 把另一文件的这一处**推过来** |
| `:diffget` | 拉当前差异块 |
| `:diffput` | 推当前差异块 |
| `:diffupdate` | 重新计算差异 |
| `qa` | 退出全部 |
| `:cdo` / `:cfirst` | 连续拉所有差异 |

```bash
$ vimdiff -r /etc/nginx/sites-available /etc/nginx/sites-enabled
$ vimdiff nginx.conf.orig nginx.conf
```

⚠️ **`vimdiff -r` 比对目录时两边顺序要对**（第一个是「当前」）。`do` 拉、`dp` 推，方向搞反会覆盖错误。

⚠️ **别在 vimdiff 里 `:wq` 直接保存**。vimdiff 用 `:qa` 退出，单独的窗口用 `:w`。

⚠️ **`/etc` 里的文件可能太长，vimdiff 一屏放不下**，配合 `Ctrl-w` 和 `:set number`。

## 小结

| 场景 | 命令/写法 |
|---|---|
| 改系统文件（最安全） | `sudoedit /etc/hosts` |
| 一次性指定编辑器 | `VISUAL=nano crontab -e` |
| 系统级改默认编辑器 | `sudo update-alternatives --config editor` |
| 新手编辑器 | `nano -l -w file` |
| **vim 官方教程** | **`vimtutor 1`（30 分钟最值的投入）** |
| vim 只读打开 | `vim -R file` |
| vim 崩溃恢复 | `vim -r file.swp` |
| 显示行号 | `:set nu`（永久写 `~/.vimrc`） |
| 看不可见字符 | `:set list` |
| 全文替换（安全） | `:%s/a/b/gc` |
| 只替换可视范围 | `*` 然后 `:'<,'>s/a/b/g` |
| 改当前词 | `ciw` |
| 复制一行并粘贴 | `yyp` |
| 重复上次修改 | `.` |
| 粘贴前 | `:set paste` |
| 两个文件比对 | `vimdiff f1 f2` |
| 递归比对目录 | `vimdiff -r d1 d2` |
| 改完忘保存想强退 | `:q!` |
| 无配置启动 vim | `vim -u NONE` |

**十二条铁律**

1. **改系统文件用 `sudoedit` 不用 `sudo vim`**，避免留下 root 属主的 swap 文件。
2. **`vi` 可能是 `vim.tiny`**，要用就用 `vim`。
3. **看到 `E325` / `Swap file already exists` 别急着删**，可能有人真在编辑。
4. **`u` 的撤销不跨会话**，关掉重开就没了。
5. **`.` 只重复最后一次「修改」**，粘贴后先确认位置再 `.`。
6. **`:q` 有未保存改动会拒绝**，` :q!` 是丢弃改动，没有回头路。
7. **替换里的 `.` `*` `[` 是正则**，替换字面量用 `:%s/\V.../`。
8. **替换前先 `:set number` 确认范围**，`:%s` 是全文，`:s` 只当前行。
9. **`gc` 逐个确认的替换最安全**，批量改之前用它跑一遍。
10. **`:set` 只对当前会话生效**，永久配置写 `~/.vimrc`；vimrc 写错要用 `vim -u ~/.vimrc -n -es -c q` 测。
11. **粘贴前 `:set paste`，粘完 `:set nopaste`**。
12. **改完配置文件跑一次解析器验证**（`jq` / `python3 -c 'yaml.safe_load'`），编辑器不检查格式。
