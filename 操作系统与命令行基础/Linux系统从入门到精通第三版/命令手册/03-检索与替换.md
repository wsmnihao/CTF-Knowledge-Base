# 03 · 检索与替换

三个主力：`grep` 找、`sed` 改、`awk` 处理结构化数据。
判断用哪个：

| 需求 | 用 |
|---|---|
| 找哪些行含有 X | `grep` |
| 只把行里的 X 换成 Y（整体遍历） | `sed` |
| 按列/按条件计算和格式化 | `awk` |
| 找文件、搜整个代码库 | `rg` |

---

## grep — 搜索文本

```bash
grep [选项]... 模式 [文件]...
```

| 选项 | 作用 | 记忆点 |
|---|---|---|
| `-i` | 忽略大小写 | ignore |
| `-v` | **反向**：输出**不**匹配的行 | invert |
| `-c` | 只输出匹配行数 | count |
| `-l` | 只输出**文件名**（有匹配就输出一次） | files-with-matches |
| `-L` | 只输出没有匹配的文件名 | |
| `-n` | **输出行号** | number |
| `-r` | 递归目录（跟随符号链接） | |
| `-R` | 递归且**跟随所有符号链接** | |
| `-E` | **扩展正则**（`\|` `\+` `?` `{n}`） | extended |
| `-F` | **固定字符串**，不当正则 | fixed |
| `-o` | 只输出匹配到的**那一部分** | only-matching |
| `-w` | 全词匹配（不匹配 `hello` 里的 `ell`） | word |
| `-x` | 整行完全匹配 | |
| `-A N` | 显示匹配行**之后** N 行 | after |
| `-B N` | 显示匹配行**之前** N 行 | before |
| `-C N` | 显示前后各 N 行 | context |
| `-q` | 静默，有匹配退出码 0，无匹配 1 | quiet |
| `-m N` | 每个文件最多匹配 N 次后停 | max-count |
| `-e` | 指定多个模式，可重复 | |
| `-f 文件` | 模式从文件读 | |
| `--include` / `--exclude` | 按文件名模式筛选 | |
| `--color=auto` | 匹配处上色 | |
| `-P` | PCRE（GNU 扩展，支持 `\d` `(?<=)`） | |
| `-z` | 把 NUL 当行分隔（处理含换行的文件名） | |

```bash
# 最常用的四种
$ grep "error" app.log                # 找含 error 的行
$ grep -in "error" app.log            # 忽略大小写 + 行号
$ grep -v "^#" config.yaml            # 去掉注释行
$ grep -rn "TODO" src/                # 递归整个目录

# 多模式
$ grep -E "ERROR|FATAL" app.log
$ grep -e "error" -e "fatal" app.log  # 等价，少打字

# 固定字符串（路径里有 . * 时必须用，否则被当正则）
$ grep -F "192.168.1.1" file          # '.' 不会被当通配
$ grep -rn "a.b" .                    # '.' 是任意字符，会误匹配
$ grep -rFn "a.b" .                   # 正确

# 上下文：看报错前后
$ grep -n -C 3 "FATAL" app.log

# 只列出哪些文件有
$ grep -rl "TODO" src/

# 只取匹配的那部分（提取用）
$ grep -oE '[0-9]{1,3}(\.[0-9]{1,3}){3}' app.log   # 抽出所有 IP
$ grep -oP '(?<=user=)\w+' app.log                  # PCRE 后顾断言

# 只要 IP 列（配合正则提取）
$ awk '{print $1}' access.log | grep -oE '^[0-9.]+'

# 排除某类文件
$ grep -rn --include='*.py' "import os" src/
$ grep -rn --exclude-dir={.git,node_modules,__pycache__} "TODO" .
```

⚠️ **`grep` 默认会跳过二进制文件**并打印 `Binary file ... matches`。要它处理二进制加 `-a`（`--text`）。

⚠️ **`grep -r` 跟随命令行上给的符号链接，但不跟随递归遇到的符号链接**（这是防循环的设计）。要跟就得用 `-R`。**这是 `-r` 和 `-R` 的唯一区别。**

⚠️ **正则里的 `.` `*` `[` 都是元字符**。搜字面量必须 `grep -F`。搜 `192.168.1.1` 用普通 grep 会连 `192x168y1z1` 一起匹配出来。

⚠️ **`-i` 加了 `-E` 时某些实现对非 ASCII 大小写处理不一致**，中文没有大小写问题，英文注意。

⚠️ **`grep -q` 一定要配 `&&` 或 `if`，不能单独跑**。`-q` 什么都不输出，只看退出码。

⚠️ **匹配整个单词用 `-w`**，搜 `log` 别把 `login`、`dialog` 一起匹配进来。**搜代码时几乎总要加 `-w` 或用更精确的模式。**

⚠️ **`.` 不匹配换行**。要跨行匹配加 `-z`，或用 `perl -0777`。

⚠️ **超长行**（比如一条 JSON）grep 能处理，但 `-C` 上下文会把终端刷爆。

⚠️ **中文正则在 GNU grep 下可用**，但要注意 `--color` 输出里中文可能对不齐。

## rg — ripgrep，更快的递归搜索

Rust 写的 grep 替代品，默认忽略 `.gitignore`、跳过隐藏文件、支持并行。

```bash
rg [选项]... 模式 [路径]...
```

| 选项 | 作用 |
|---|---|
| `-i` / `--ignore-case` | 忽略大小写 |
| `-v` / `--invert-match` | 反向 |
| `-n` / `--line-number` | 行号（**默认就有**） |
| `-c` / `--count` | 计数 |
| `-l` / `--files-with-matches` | 只列文件名 |
| `-L` / `--files-without-match` | 列无匹配的文件 |
| `-o` / `--only-matching` | 只输出匹配部分 |
| `-w` / `--word-regexp` | 全词 |
| `-g` / `--glob` | 按 glob 筛选，如 `-g '*.py'` |
| `-g '!*.min.js'` | 排除 |
| `--hidden` | **搜隐藏文件**（默认跳过） |
| `--no-ignore` | 连 `.gitignore` 也搜（**注意会搜 `.git` 目录**） |
| `-t` / `--type` | 按文件类型，如 `-t py` |
| `-T` / `--type-not` | 排除类型 |
| `--pcre2` | 启用 PCRE2，支持后顾断言 |
| `--multiline` | 跨行（`.` 可匹配 `\n`） |
| `--stats` | 结尾输出统计 |
| `-A/-B/-C N` | 上下文（与 grep 相同） |
| `--color=always` | 强制上色 |

```bash
# 递归搜索整个代码库（自动跳过 .gitignore 里的东西）
$ rg "TODO"

# 只搜 Python
$ rg -t py "def main"

# 按 glob 筛选
$ rg -g '*.js' -g '!*.min.js' "fetch\("

# 搜隐藏文件
$ rg --hidden "API_KEY"

# 提取所有邮箱
$ rg -oP '[\w.+-]+@[\w-]+\.[\w.]+' notes.txt

# 统计每个文件命中次数
$ rg -c "error" --stats

# 跨行匹配
$ rg --multiline 'foo.*\n.*bar'

# 找文件而不是找内容
$ rg --files -g '*.yaml' -g '!*lock*'

# 后顾断言（grep -P 也能做，但 rg 更快）
$ rg --pcre2 '(?<=PORT=)\d+'
```

⚠️ **rg 不是系统自带的**。装：`sudo apt install ripgrep`（Ubuntu 24.04 仓库里有）。

⚠️ **rg 默认不搜隐藏文件、不搜被 `.gitignore` 忽略的文件**。这是它的优点（搜代码库快且干净），但**搜 `/etc` 这类系统目录时必须加 `--hidden --no-ignore`**，否则会漏掉 `~/.ssh/config`、`/etc/apt/sources.list.d/*` 之类的文件。

⚠️ **`--no-ignore` 会让它钻进 `.git`**，结果里混一堆对象文件。加 `--glob '!.git/**'`。

⚠️ **rg 默认输出不带 `--heading` 的文件名**，多文件搜索时容易分不清哪个匹配来自哪个文件。用 `--heading` 或 `--with-filename`。

## sed — 流式编辑器

sed 按行读入、逐行处理、逐行输出。核心是「**地址 + 命令**」。

```
sed [选项]... {地址}命令[文件]
```

**地址（哪些行）**

| 地址 | 含义 |
|---|---|
| `4` | 第 4 行 |
| `1,5` | 1 到 5 行 |
| `2,$` | 第 2 行到末尾 |
| `/error/` | 含 `error` 的行 |
| `0~4` | 每 4 行一次（`~` 步进） |
| `/start/,/end/` | 从匹配 start 到匹配 end 之间 |

**命令（做什么）**

| 命令 | 作用 |
|---|---|
| `s/找/换/g` | 替换，`g` = 一行内全部替换（**不加 g 只换第一个**） |
| `d` | 删除本行 |
| `p` | 打印本行（配合 `-n` 才有意义） |
| `q` | 退出 |
| `a` / `i` / `c` | 后面追加 / 前面插入 / 整行替换 |
| `y/abc/xyz/` | 逐字符替换 |
| `=` | 打印行号 |
| `s///` | 替换，`&` 代表匹配到的内容 |

| 选项 | 作用 |
|---|---|
| `-i[后缀]` | **原地修改**，`-i.bak` 留备份（**强烈建议**） |
| `-n` | 不自动打印，只执行 `p` |
| `-E` / `-r` | 扩展正则 |
| `-e` | 多条命令，`sed -e 'a' -e 'b'` |
| `-f 脚本文件` | 从文件读命令 |
| `-z` | 用 NUL 分隔而非换行 |
| `s///I` | 忽略大小写替换（GNU） |

```bash
# 替换：最常用
$ sed 's/old/new/' file.txt              # 每行第一个
$ sed 's/old/new/g' file.txt             # 每行全部（最常用）
$ sed -i 's/old/new/g' file.txt          # 原地改
$ sed -i.bak 's/old/new/g' file.txt      # 原地改 + 留 .bak（推荐）

# 只在特定行范围替换
$ sed '1,10s/old/new/g' file
$ sed '/TODO/,/DONE/s/^/ /' file

# 删行
$ sed '/^#/d' config.yaml                # 删所有注释行
$ sed '/^$/d' file                       # 删所有空行
$ sed '5d' file                           # 删第 5 行
$ sed '1!d' file                          # 只留第 1 行

# 只打印匹配行（= grep）
$ sed -n '/error/p' app.log
$ sed -n '10,20p' file                   # 打 10-20 行
$ sed -n '10~5p' file                    # 每 5 行打一次
$ sed -n '$p' file                       # 最后一行

# 加行
$ sed '/^\[server\]/a\    new = value' config
$ sed '5i\    inserted line' file
$ sed '5c\    replaced line' file

# 用变量
$ name=web
$ sed "s/HOST/$name/g" config

# 引用匹配内容
$ sed 's/[0-9]\{3\}/&/g' file             # 数字后面再加自己（用于分组）
$ sed -E 's/^([^:]+):.*/\1/' /etc/passwd  # 用捕获组

# 转义
$ sed 's/a\/b/c\/d/g' file               # 模式里的 / 要转义
$ sed 's#/old#/new#g' file               # 或换分隔符，不用转义（更省事）
$ sed 's/^[[:space:]]*//' file            # 删行首空白

# 多条命令
$ sed -e 's/^[[:space:]]*//' -e 's/[[:space:]]*$//' file

# 加行号输出
$ sed -n '=' file | paste - - file

# 提取字段（配合 grep）
$ grep '^root:' /etc/passwd | sed -E 's/^[^:]+:[^:]+:[^:]+:([^:]+).*/\1/'
```

⚠️ **`s` 不加 `g` 只替换每行的第一个匹配**。这是最常见的"为什么只改了一部分"。

⚠️ **`-i` 是原地修改，没有撤销，没有备份**。**永远写 `-i.bak`**，尤其是批量改配置文件。养成这个习惯的成本是 3 个字符。

⚠️ **`sed -i` 在 GNU 和 BSD/macOS 上语法不同**：GNU 是 `sed -i 's/a/b/' f`，macOS 必须写 `sed -i '' 's/a/b/' f`（备份后缀是独立参数）。**写脚本要兼容时用 `sed -i.bak` 形式，GNU 正常，BSD 需要注意。**

⚠️ **`sed` 默认每行都打印**。`-n` 关掉自动打印后，只有显式 `p` 的行才输出。这是 `sed -n '/x/p'` 能当 `grep` 用的原因。

⚠️ **`a`/`i`/`c` 后的文本必须用反斜杠转义或写成单独一行**，多行文本用 `\` 续行。格式错了报错信息很难懂。

⚠️ **特殊字符要转义**：`/`（用 `#` 当分隔符可免）、`&`、`.` `*` `[` `^` `$`。搜字面量用 `sed 's/a.b/.../'` 会把 `axb` 也换掉。

⚠️ **`sed` 是逐行流式**，不理解结构。它没法解析 JSON、CSV 里的嵌套。**结构化数据用 `awk` 或 `jq`。**

⚠️ **`sed 's/a/b/'` 不处理二进制**，也不处理没有末尾换行的文件（GNU 会补一个）。

## awk — 按列处理

awk 读一行、拆成字段、对字段做计算。**处理表格类数据的第一选择。**

```bash
awk [选项]... '模式 { 动作 }' [文件]
```

**核心概念**

| 名字 | 含义 |
|---|---|
| `$0` | 整行 |
| `$1` `$2` | 第 1、第 2 个字段 |
| `$NF` | **最后一个字段** |
| `NF` | 本行字段数 |
| `NR` | 已读总行数（行号） |
| `FNR` | 当前文件的行号（多文件时用） |
| `FS` | 输入字段分隔符 |
| `OFS` | 输出字段分隔符（默认单空格） |
| `ORS` | 输出行分隔符 |
| `RS` | 输入记录分隔符（默认换行） |

| 选项 | 作用 |
|---|---|
| `-F 符` | 指定字段分隔符 |
| `-v 名=值` | 传变量进去（**必须用它传字符串，shell 会吃掉引号**） |
| `-f 文件` | 程序从文件读 |

**结构**

```bash
awk 'BEGIN{ 初始化 } 逐行处理 { 动作 } END{ 收尾 }'
```

```bash
# 取列
$ awk '{print $1}' /etc/passwd
$ awk -F: '{print $1, $7}' /etc/passwd
$ awk -F: '{print $NF}' /etc/passwd            # 最后一列
$ awk -F, '{print $2}' data.csv

# 带条件
$ awk '$3 > 1000 {print $1}' /etc/passwd        # 只打印第3列>1000的行
$ awk 'NR>1 {print}' data.csv                   # 跳过表头
$ awk '/^root/ {print}' /etc/passwd

# 多条件
$ awk '$3>=1000 && $4<65536' /etc/passwd        # UID 和 GID 范围
$ awk '$1=="/" || $1=="/home"' fstab

# 统计
$ awk '{sum += $1} END {print sum}' numbers.txt
$ awk '{s+=$3} END {printf "总计: %.2f\n", s}' data.txt
$ awk 'END {print NR}' file                     # 行数（等价 wc -l）
$ awk '{print NF}' file | sort -u               # 有几种字段数（查列数不一致）

# 格式化输出
$ awk '{printf "%-20s %8.2f\n", $1, $2}' data.txt
$ awk 'BEGIN {printf "%-10s %5s %s\n", "NAME","SIZE","DESC"}'

# 字符串处理
$ awk '{gsub(/old/, "new"); print}' file        # 全部替换（相当于 sed）
$ awk -F: '{print toupper($1)}' /etc/passwd
$ awk '{print length($0)}' file                 # 长度
$ awk '{print substr($0, 1, 10)}' file          # 截取

# 数组统计（awk 的强项）
$ awk '{count[$1]++} END {for (ip in count) print count[ip], ip}' access.log \
    | sort -rn | head -10
$ awk '{gsub(/\r/,""); status[$9]++} END {for (s in status) print s, status[s]}' access.log

# 多文件
$ awk 'FNR==1 {print "=== " FILENAME " ==="} {print}' f1 f2

# 内置函数
$ awk '{print length($0)}'
$ awk -F: '{print substr($0, index($0,":")+1)}'
$ awk 'BEGIN {print int(7/2), 7%2, 2^10}'
$ awk 'BEGIN {srand(); print rand()}'

# 传变量
$ awk -v threshold=100 '$3 > threshold {print $1, $3}' data.txt
```

⚠️ **awk 的数组是无序的**。`for (k in arr)` 遍历顺序不保证，要有序输出必须再管道给 `sort`。需要有序就用数组下标而非关联数组。

⚠️ **`awk` 的字符串拼接是直接相连**，不是相加：`$1 $2` 是拼接，`$1+$2` 是数值相加。混用容易得到 `01` 这种结果。

⚠️ **`-v` 传的字符串在 awk 里是"字符串"不是"数字"**，比较时会按字符串比。数字阈值用 `-v n=100` 传进来后如果没被识别为数字，条件会失效。稳妥做法是 `awk -v n=100 '$3+0 > n+0'`。

⚠️ **`$0` 改不了要用 `$0 = ...`**。写 `$1 = "x"` 只会改字段 1，不会重建整行。

⚠️ **awk 变量名区分大小写**，`count` 和 `Count` 是两个变量。而且 awk 有内建变量（`FS` `NR` `NF` `OFS`…），**起名别撞上**。

⚠️ **处理含引号的 shell 参数很痛苦**。awk 程序本身用单引号包，里面要写单引号得用 `'\''` 转义。更简单的办法是写进文件用 `awk -f`。

⚠️ **`awk` 默认按空白分字段，连续空格会产生空字段**。用 `-F:` 或 `-F'\t'` 指定单字符分隔符才不会。

⚠️ **Windows 来的文件带 `\r`**，`$NF` 里会混进 `\r`。先 `tr -d '\r'` 或在 awk 里 `gsub(/\r/,"")`。

⚠️ **`awk` 实现有方言**（mawk / gawk / original-awk）。Ubuntu 默认 `mawk`，功能少一些（如不支持 `gensub`、某些多维数组技巧）。需要 gawk 特性时 `sudo apt install gawk` 并用 `gawk`。

## shellcheck — 检查 shell 脚本

```bash
shellcheck [选项]... 脚本...
```

| 选项 | 作用 |
|---|---|
| `-s` / `--shell` | 指定 shell：`bash` `sh` `dash` `ksh` |
| `-f` | 指定格式：`gcc` `checkstyle` `diff` `json` `quiet` |
| `-e` | 指定要排除的检查项编号，如 `-e SC2086` |
| `-i` | 信息级别以上都报 |

```bash
$ shellcheck script.sh
$ shellcheck -s bash script.sh
$ shellcheck -f gcc script.sh 2>&1 | less
$ shellcheck -e SC2086 script.sh    # 忽略指定项
```

**它能查出来的典型问题**

| 编号 | 问题 |
|---|---|
| SC2086 | 变量没加引号（`rm $file` 遇到空格会出错） |
| SC2046 | `$(...)` 没加引号 |
| SC2148 | 缺 shebang |
| SC2006 | 反引号应换成 `$()` |
| SC2164 | `cd` 失败没处理（应加 `|| exit`） |
| SC2035 | `*` 没加引号 |
| SC2015 | `A && B || C` 逻辑不可靠 |

⚠️ **shellcheck 不检查逻辑对错**，只查 shell 层面的坑。跑通了不代表脚本对。

⚠️ **它是 lint 不是执行**。不会真跑你的脚本，所以没有副作用。但它也无法知道你的外部环境。

⚠️ **不是系统自带的**。`sudo apt install shellcheck`（Ubuntu 仓库有）。

## jq — 处理 JSON（★ 现代运维必备）

```bash
jq [选项]... 过滤器 [文件...]
```

| 选项 | 作用 |
|---|---|
| `-r` | **输出原始字符串（不加会带引号）** |
| `-c` | 紧凑输出（单行） |
| `-n` | **null 输入（用来构造 JSON）** |
| `-e` | 输出为 `false`/`null` 时退出码非 0（脚本判断用） |
| `-s` | 把整个输入当一个数组 |
| `-a` | 原样输出 ASCII（防转义） |
| `-S` | 键排序 |
| `-f 过滤器文件` | 从文件读过滤器 |
| `--arg 名字 值` | **给 `$名字` 传值** |
| `--rawfile 名 文件` | 把文件内容传进来 |
| `--argjson` | 传 JSON 片段（不是字符串） |
| `--tab` / `--indent n` | 缩进 |

**十个最常用过滤器**

| 过滤器 | 作用 |
|---|---|
| `.` | 整个文档 |
| `.key` | 取字段 |
| `.a.b.c` | 嵌套取 |
| `.[]` | 遍历数组所有元素 |
| `.[] \| .name` | ⭐ 遍历取某字段 |
| `.key[0]` | 数组第一个 |
| `.key[]` | 数组展开成多个输出 |
| `.key \| length` | **长度** |
| `.key[] \| select(.x > 5)` | **条件过滤** |
| `keys` / `keys_unsorted` | 所有键 |
| `to_entries` / `from_entries` | 键值互转 |
| `map(.x)` | 对每个元素做一件事 |
| `add` / `unique` / `sort_by(.x)` | 求和 / 去重 / 排序 |
| `with_entries(.value += 1)` | 批量改 |
| `del(.key)` | 删字段 |
| `env` | 全部环境变量 |

```bash
# 提取（-r 一定要加，否则输出带引号）
$ curl -s https://api.example.com/info | jq -r '.version'
$ curl -s https://api.example.com/list | jq -r '.[].name'
$ curl -s https://api.example.com/u/1 | jq -r '.data.items[] | "\(.id)\t\(.title)"'

# 过滤
$ jq -r '.[] | select(.status == "active") | .email' users.json
$ jq -r '.items[] | select(.score > 80) | .name' result.json

# 统计
$ jq '. | length' array.json
$ jq -r '.[].price | add' orders.json
$ jq -r 'group_by(.dept)[] | "\(.[0].dept): \(length)"' staff.json
$ jq -r 'map(.age) | max, min, add/length' staff.json

# 构造 JSON（管道传参）
$ jq -n --arg name liu --argjson uid 1000 '{user:$name, uid:$uid}'
$ echo '{"a":1}' | jq '. + {b:2}'
$ jq '. * .' obj.json

# 校验 + 格式化
$ jq . config.json >/dev/null && echo "JSON 合法"
$ jq . config.json                       # 美化输出
$ jq -c . big.json                       # 压成一行（给 curl 用）
$ jq -c . big.json | curl -d @- http://api

# 处理多行 JSON（每行一个对象）
$ cat ndjson.log | jq -c -s 'group_by(.level)[] | {lvl:.[0].level, n:length}'
```

⚠️ **不加 `-r` 输出字符串会带双引号**。`jq -r '.name'` 得到 `liu`，`jq '.name'` 得到 `"liu"`。**这是 jq 最常见的坑。**

⚠️ **jq 不是 Ubuntu 自带的**。`sudo apt install jq`。装完确认 `jq --version`。

⚠️ **jq 的语法不是 shell**：`$name` 是 jq 自己的变量（由 `--arg` 传入），**和 shell 变量没关系**。在单引号里写 `$name` 是传给 jq 的。

⚠️ **`.[]` 和 `.[]?` 的区别**：数组元素可能为 `null` 时用 `.[]?`，否则 jq 整个报错退出。

⚠️ **大文件别直接 `jq .` 整个加载**（内存爆）。用流式的 `--stream` 或先 `head`。

⚠️ **`jq` 的错误信息在 stderr 且不带文件名**。多个文件一起处理时用 `jq -r '...' a.json b.json` 或 `--slurpfile` 更清楚。

⚠️ **在管道里 `jq` 失败会影响整条管道的结果**。脚本里用 `jq -e` 让退出码可用。

## bc / expr — 算术与浮点

```bash
bc [选项]                        # 交互式或从 stdin 读
expr 表达式                     # 一次性算
```

| bc 选项 | 作用 |
|---|---|
| `-l` | **加载数学函数（`sin` `ln` `sqrt`）** |
| （无） | **scale 默认 0（小数位为 0，结果取整）** |

```bash
# bc 默认不认小数，必须先设 scale
$ echo 'scale=2; 10/3' | bc
3.33

$ echo 'scale=10; 22/7' | bc
3.1428571428

$ echo 'l(2); p' | bc -l      # ln(2)
$ echo 'scale=4; sqrt(2)' | bc -l
$ echo 'scale=2; 3^10' | bc   # 幂

# 一步算完
$ echo 'scale=2; 100*1.15' | bc

# expr（整数，只有整数运算）
$ expr 3 + 4                  # 7
$ expr 10 / 3                 # 3（整数除法，不是 3.33）
$ expr length "hello"         # 5
$ expr substr "hello" 2 3    # ell

# 在 shell 里做整数运算（不需要外部命令）
$ n=10; echo $((n * 2))
$ ((n > 5)) && echo "大于5"

# 字节/容量计算
$ echo 'scale=2; 1024*1024*1.5/1024/1024' | bc   # 1.50
```

⚠️ **bc 不在 `PATH` 时是 `bc` 没装**。Ubuntu 里是 `bc` 包（最小安装可能没有）。**`awk` 也能算（`awk 'BEGIN{print 10/3}'`），且几乎总是已装**，脚本里用 awk 更保险。

⚠️ **`$((10/3))` 是整数除法得 3**，不是 3.33。要小数用 `bc` 或 `awk`。

⚠️ **`expr` 只处理整数**，且因为是历史命令，**shell 里做条件判断不要用 `expr`**，用 `[[ ]]` 或 `$(( ))`（见 [09-Shell与脚本基础.md](09-Shell与脚本基础.md)）。

⚠️ **bc 读 stdin 直到 EOF**，脚本里要 `echo '...' | bc` 或 `bc <<< '...'`。忘了关会挂住。

⚠️ **浮点比较不要用 bc 判断相等**：`scale` 设大了会掩盖差异。要判断相等用整数或 `awk`。

## 三者配合的经典组合

```bash
# 提取一列
$ cut -d: -f1 /etc/passwd
$ awk -F: '{print $1}' /etc/passwd

# 只在含某词的行里替换（grep 筛 + sed 改）
$ grep -n 'localhost' config.yaml | sed 's/localhost/0.0.0.0/'

# 替换复杂结构（sed 做不到时用 awk）
$ awk -F: 'BEGIN{OFS=":"} {$3="1000"; print}' /etc/passwd > new

# 日志统计三连
$ awk '{print $1}' app.log | sort | uniq -c | sort -rn | head

# 搜索并批量改（先看，再改）
$ rg -l "old-api" src/          # 1. 哪些文件
$ rg -n "old-api" src/          # 2. 哪些行
$ rg -l "old-api" src/ | xargs sed -i.bak 's/old-api/new-api/g'   # 3. 改

# 检查所有配置里的明文口令
$ rg -n 'password\s*=\s*\S+' /etc/

# 提取配置项
$ rg -oP '^\s*\w+=\K.*' env.sh
```

⚠️ **`grep | sed` 有个隐患**：如果文件只有一行且没换行，或行里有特殊字符，两次处理的结果可能对不上。**结构化的改动一律用 `awk` 一次完成**，避免多次遍历。

⚠️ **在文件上用 sed -i 之前先 `cp` 备份**，或者用 `-i.bak`。批量改动（`xargs sed -i`）尤其要。

## 小结

| 场景 | 命令 |
|---|---|
| 找含某词的行 | `grep -n "词" file` |
| 只列哪些文件有 | `grep -rl "词" src/` |
| 搜整个代码库（快） | `rg "词"` |
| 看匹配前后文 | `grep -n -C 3 "词" file` |
| 搜字面量（带 `.` `*`） | `grep -F "a.b"` |
| 原地替换（带备份） | `sed -i.bak 's/旧/新/g' file` |
| 删注释行 | `sed '/^#/d' file` |
| 只打印匹配行 | `sed -n '/词/p' file` |
| 取第 n 列 | `cut -d: -f1` 或 `awk -F: '{print $1}'` |
| 按条件计算求和 | `awk '$3>100 {s+=$5} END {print s}' data` |
| 频次 Top N | `awk '{print $1}' f \| sort \| uniq -c \| sort -rn \| head` |
| **取 JSON 字段** | **`jq -r '.a.b[].name' f.json`** |
| **JSON 条件过滤** | **`jq -r '.[] \| select(.x>5) \| .name' f.json`** |
| **算小数** | **`echo 'scale=2;10/3' \| bc`** 或 `awk 'BEGIN{print 10/3}'` |
| 查脚本 shell 坑 | `shellcheck script.sh` |

**十条铁律**

1. **`grep` 搜字面量加 `-F`**，否则 `.` `*` 会误匹配。
2. **`sed -i` 一定写 `-i.bak`**，没有撤销。
3. **`sed` 的 `s///` 不加 `g` 只换每行第一个**。
4. **改文件前先备份**：`-i.bak` 或 `cp file file.orig`。
5. **批量改用「三步走」**：`rg -l` 看清单 → `rg -n` 看行 → 才动手改。
6. **`jq` 输出字符串一定要 `-r`**，否则带引号。
7. **`$((10/3))` 是整数除法得 3**；要小数用 `bc`（记得 `scale=`）或 `awk`。
8. **结构化改动一次用 `awk` 完成**，不要 `grep | sed` 两次遍历。
9. **Windows 来的文件先 `tr -d '\r'`**，否则每行末尾多一个 `\r` 会让匹配全部失败。
10. **`grep`/`sed`/`awk` 都改不了二进制文件**。改之前 `file` 确认类型。
