# 02 · 文本查看与处理

> 文本是 Linux 的原生数据格式：配置、日志、源码、CSV 全是纯文本。
> 这一章的命令构成一条典型流水线：`cat`/`head` 读入 → `grep` 筛选 → `sort`/`uniq` 聚合 → `cut`/`awk` 取列 → `tee` 落盘。

---

## cat — 输出整个文件

```bash
cat [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-n` | 所有行编号（`-b` 只给非空行编号） |
| `-s` | 连续空行压成一行 |
| `-A` | 显示所有不可见字符（`$` 行尾、`^I` 制表符） |
| `-t` | 只显示制表符为 `^I` |
| `-e` | 行尾显示 `$` |
| `-v` | 显示非打印字符 |

```bash
$ cat notes.txt
$ cat -n config.yaml          # 带行号看配置，报错时能对上
$ cat -A script.sh             # 看真实的换行和制表符
$ cat file1 file2              # 多个文件直接接一起
```

⚠️ **`cat` 是给小于一屏的文件用的**。文件大到需要滚动时才换 `less`，否则刷屏且无法回看。

⚠️ **`cat *` 遇到二进制会毁掉终端**。用 `file` 先判断，或 `cat` 前加 `-v`。

⚠️ `cat a > b` 和 `cp a b` 都能复制，但 `cat a > b` **在 `a` 和 `b` 同一个文件时会把文件清空**。同文件用 `cp`。

## head / tail — 头几行 / 尾几行

```bash
head [选项]... [文件]...
tail [选项]... [文件]...
```

| 选项 | 作用 | head | tail |
|---|---|---|---|
| `-n N` | 取 N 行（`-5` 等价 `--lines=5`） | ✅ | ✅ |
| `-c N` | 取 N 字节 | ✅ | ✅ |
| `-q` | 多文件时不打文件名头 | ✅ | ✅ |
| `-f` | **持续追加新内容** | ❌ | ✅ |
| `-F` | 同 `-f`，但文件被轮转也能跟上 | ❌ | ✅ |
| `-v` | 打印行号（配合 `-f` 看新增内容） | ❌ | ✅ |

```bash
$ head config.yaml
$ head -n 20 /var/log/syslog
$ tail -n 100 /var/log/syslog

# 实时跟踪日志
$ sudo tail -f /var/log/nginx/error.log

# 跟踪且文件会被 logrotate 轮转
$ sudo tail -F /var/log/nginx/error.log

# 跟踪时带行号，方便对照
$ sudo tail -f -v -n 0 /var/log/syslog | grep ERROR
```

⚠️ **`head -5 f` 不带空格能用**（`-5` 形式），但 `tail -f` 这种长选项**必须带空格**。混着写容易错。

⚠️ **`-f` 跟的是 inode，不是文件名**。`logrotate` 把日志重命名后另开新文件，`tail -f` 会死盯旧文件不动；`-F` 会检测重开。**看生产日志用 `-F`。**

⚠️ **`tail -f` 按 `Ctrl+C` 退出，不是 `q`**。

⚠️ 默认 `tail` 输出 **10 行**、`head` 也是 **10 行**，与 `-n` 无关。

## less — 分页查看（可交互）

系统自带的翻页器，比 `more` 好用得多。

```bash
less [选项]... [文件]...
```

| 按键 | 作用 |
|---|---|
| `空格` / `b` | 下翻 / 上翻 一屏 |
| `↓` `↑` `j` `k` | 下移 / 上移 一行 |
| `/关键词` | **向下搜索** |
| `?关键词` | 向上搜索 |
| `n` / `N` | 跳到下一个 / 上一个匹配 |
| `g` / `G` | 跳到文件**开头 / 结尾** |
| `q` | 退出 |
| `+n`（启动参数） | 直接跳到第 n 行 |
| `-S` | **不折行**，长行左右滚动 |

```bash
$ less /var/log/syslog
$ less -S wide.log            # 不折行，看长配置必备
$ less +100 error.log         # 直接看第 100 行
$ less +/pattern file         # 定位到第一个匹配处
$ less -N file                # 行尾显示行号

# 管道进去
$ ps aux | less
$ dmesg | less
```

⚠️ **`q` 退出，不是 `Ctrl+C`**。用 `more` 时 `q` 可能无效。

⚠️ **长行默认折行**，看日志列对不齐时用 `-S`。很多人在这里误以为文件坏了。

⚠️ **管道给 `less` 时用 `|` 会丢掉滚动**。要存又要看：`| tee out.log | less`。

⚠️ `more` 的按键在不同实现间不统一，`less` 才是可预期的。系统都预装 `less`。

## wc — 计数

```bash
wc [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-l` | 行数 |
| `-w` | 单词数 |
| `-c` | 字节数 |
| `-m` | **字符数**（多字节文本下和 `-c` 不同） |
| `-L` | 最长行长度 |

```bash
$ wc notes.txt
  42  315 1890 notes.txt      # 顺序固定：行 词 字节

$ wc -l notes.txt             # 只看行数，最常用
$ wc -l *.log                 # 一次统计多个
$ cat access.log | wc -l     # 数一共有多少请求
```

⚠️ **输出顺序永远是 行 词 字节**，不能按你输入的选项顺序排。想要纯数字方便做算术，加 `-c` 或用 `awk`：

```bash
$ echo "文件数: $(ls -1 | wc -l)"
```

⚠️ **`wc -l` 数的是换行符个数，不是"行数"**。最后一行没有换行符的文件，会少算 1。这是 `wc` 最常被质疑的地方。

⚠️ **中文的 `-c` 和 `-m` 差很多**：`wc -c` 是字节（一个汉字 3 字节），`wc -m` 才是字符。

## nl — 带行号输出

```bash
nl [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-b a\|t\|n` | 编号范围：全部 / 非空行 / 都不编号 |
| `-w N` | 行号字段宽度 |
| `-s S` | 行号后的分隔符（默认制表符） |

```bash
$ nl notes.txt
     1  第一行
     2  第二行

$ nl -ba -w4 -s': ' notes.txt      # 全部编号，宽度4，冒号分隔
$ nl -ba -v2 notes.txt              # 从第 2 行开始编号
```

⚠️ **`cat -n` 和 `nl` 的编号规则不同**：`cat -n` 给所有行编号，`nl` 默认只给非空行编号。要全编号用 `nl -ba`。

⚠️ **`nl` 不改文件内容**，只是输出时加编号。要把编号写进文件得重定向。

## cut — 按列或位置截取

```bash
cut [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-d 符` | 指定**分隔符**（单个字符） |
| `-f 列表` | 取哪些字段，如 `1` `1,3` `1-3` `2-` `-1` |
| `-c 列表` | 按**字符位置**取 |
| `--complement` | 取**没选中**的（GNU） |
| `-s` | 不处理不含分隔符的行 |

```bash
# 按分隔符
$ cut -d: -f1 /etc/passwd                 # 只要用户名
$ cut -d: -f1,7 /etc/passwd               # 用户名 + shell
$ cut -d: -f1-3 /etc/passwd               # 前三列
$ cut -d, -f2,4 data.csv                  # CSV 取第 2、4 列

# 按字符
$ cut -c1-8 file                           # 每行前 8 个字符

# 取反
$ cut -d: --complement -f7 /etc/passwd    # 除 shell 外的所有列
```

⚠️ **`-d` 后面只能跟一个字符**。分隔 CSV 里的逗号可以，制表符要写 `-d $'\t'`，多个字符不行。

⚠️ **`cut` 不理解字段里的分隔符**。`cut -d, -f2` 遇到 `a,"b,c",d` 会切错。字段内有分隔符时必须用 `awk -F, '{print $2}'` 之外的办法，或 `python -c 'import csv'`。这是 `cut` 最硬的天花板。

⚠️ **`cut` 按字节/字符切，不按"列"理解**。要真正的列处理用 `awk`。

⚠️ **没有 `-f` 就没有输出**。`cut -d: /etc/passwd` 什么都不输出，必须配 `-f`。

⚠️ 默认**保留行尾**，切出来的字段常带 `\n`，接管道时可能多出空行。`head -n -1` 或 `tr -d '\n'` 处理。

## paste — 横向拼接

`cut` 是竖着切，`paste` 是横着拼。

```bash
paste [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-d 符` | 输出分隔符（默认制表符） |
| `-s` | **把每个文件的所有行粘成一行**（而不是文件间粘） |

```bash
$ cut -d: -f1 names.txt > a.txt
$ cut -d: -f7 names.txt > b.txt
$ paste a.txt b.txt                # 两列并排
$ paste -d: a.txt b.txt           # 冒号分隔

# 每行内的字段横着拼成一行
$ paste -s names.txt
alice,bob,carol
```

⚠️ **`paste` 不加 `-s` 是「文件间」粘，`-s` 是「文件内」粘**。这是最容易搞反的一个选项。

⚠️ **`paste` 用 `-d` 要转义制表符**：`paste -d$'\t'` 或 `paste -d '\t'`。

## sort — 排序

```bash
sort [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-n` | 数值排序（**不写就是字典序**） |
| `-h` | 人类可读数值，支持 `2K` `1M` `3G` |
| `-r` | 逆序（降序） |
| `-u` | 去掉重复行（等于 `sort \| uniq`） |
| `-k 字段` | 指定排序键，如 `-k2` `-k2,2` `-k2n` |
| `-t 符` | 指定字段分隔符 |
| `-n` 前缀 | `-V` 版本号排序 |
| `-f` | 忽略大小写 |
| `-b` | 忽略前导空格 |
| `-c` / `-u` / `-C` | 只检查是否已有序 |

```bash
$ sort names.txt                 # 字典序
$ sort -n numbers.txt            # 数值（9 在 10 前面）
$ sort -h sizes.txt              # 2K 排在 1M 前面
$ sort -r scores.txt             # 降序
$ sort -k3 -t: /etc/passwd       # 按第 3 列（GID）排

# 大文件加速：先排序再管道
$ sort -h sizes.txt | head -10

# 版本号排序
$ printf '1.10\n1.9\n1.2\n' | sort -V
1.2
1.9
1.10
```

⚠️ **不加 `-n` 就是字典序**。`sort` 会把 `10` 排在 `9` 前面，因为 `'1' < '9'`。**数字一定要 `-n`。**

⚠️ **`sort` 和 `uniq` 必须搭配使用**。`uniq` 只能去掉**相邻**的重复行，前面不排序就是白搭。

⚠️ **`sort -u` 等价于 `sort | uniq`**，但更快（省一次管道）。

⚠️ **`sort` 的字段默认从第 1 个字符开始，不是第一个字段**。`-k2` 前的空白也算在字段 1 里。要严格用第二个字段写 `-k2,2`，且可能需要 `-t` 配合。**排序字段对齐是最容易出微妙错误的地方，务必用测试数据验证。**

⚠️ **超大文件 `sort` 会吃内存**（默认全读进内存再排序）。GB 级文件用 `sort -S` 限制内存，或 `LC_ALL=C sort`。

⚠️ **`sort` 的结果在管道里会重排整个流**，后面的 `head` 拿到的是排好序的，不是原来的前几行。

⚠️ `sort -V` 是 GNU 扩展，BSD/macOS 的 `sort` 没有。

## uniq — 去重（只去相邻）

```bash
uniq [选项]... [输入]
```

| 选项 | 作用 |
|---|---|
| `-c` | **计数**，在每行前面显示出现次数 |
| `-d` | 只显示重复过的行 |
| `-u` | 只显示从未重复的行 |
| `-i` | 忽略大小写 |
| `-f N` | 跳过前 N 个字段再比较 |
| `-s N` | 跳过前 N 个字符再比较 |
| `-w N` | 只比较前 N 个字符 |

```bash
# 正确用法：先排序
$ sort access.log | uniq -c | sort -rn | head -20

# 只看重复的
$ sort names.txt | uniq -d

# 统计出现次数最多的 20 个 IP（前提是 IP 在第一列）
$ awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -20

# 文件名相同但大小写不同也算重复
$ ls | sort -f | uniq -di
```

⚠️ **`uniq` 只去相邻重复，不排序就是几乎没用**。这是 90% 的人第一次用都会踩的坑。

⚠️ **`uniq` 不能统计总数**，它没有汇总功能。要统计必须配 `sort`。

⚠️ **「出现一次的」要用 `uniq -u`**（ununique），但只在已排序的前提下。

⚠️ **只比较某一列**用 `-f N`（按字段）或 `-w N`（按字符）。不指定就是**整行**完全相同才算重复。

⚠️ `uniq -c` 的输出**用空格分隔次数和内容**，所以 `sort -rn` 排在前面、`cut -f2-` 取内容。

⚠️ 统计"前 10"的标准四步：`awk 取列 | sort | uniq -c | sort -rn | head`，最后一个 `sort -rn` 不能省——前一个只按字典序排了次数。

## tr — 字符转换

`tr` = **t**rans**r**anslate。只能处理**单个字符**，不能按字段。

```bash
tr [选项]... 集合1 [集合2]
```

| 选项 | 作用 |
|---|---|
| `-d` | 删除集合 1 的字符 |
| `-s` | 压缩连续重复字符为一个 |
| `-c` / `-C` | 补集（反转集合） |
| `-u` | 只把集合 1 转成唯一字符（去重） |

```bash
$ echo "hello world" | tr 'a-z' 'A-Z'
HELLO WORLD

$ cat file | tr -d '\r'                # 删掉 Windows 换行符（从 Windows 拷来的文件必用）
$ cat file | tr -d '\n'                # 删所有换行，拼成一行
$ cat file | tr -s ' '                 # 连续空格压成一个
$ echo "aabbcc" | tr -s 'a'            # 连续 a 压成一个 → abc
$ echo "hello" | tr -cd '[:alnum:]'    # 只保留字母数字
$ echo "abc" | tr '[:lower:]' '[:upper:]'   # 按字符类转换
```

⚠️ **`tr` 是 1:1 映射，两个集合必须等长**。`tr 'a-z' 'A-Z'` 行，`tr 'a-z' 'ABC'` 会报错。

⚠️ **`tr` 不认正则**。想用正则要 `sed` 或 `grep`。

⚠️ **`tr -d 'a'` 只删 `a`，不是删所有 `a-z`**。删整个区间写 `tr -d 'a-z'`。

⚠️ **`tr -d '\n'` 会让整个文件变成一行**，后面的 `grep` 只会输出一行，管道里极易踩。

⚠️ **从 Windows 拷来的文件**必须 `tr -d '\r'`，否则 `grep` 匹配会莫名失败。这是最常见的"明明有却搜不到"的原因。

⚠️ `tr` 的集合里 `\\` 和 `\\n` 需要单引号，否则 shell 先解释。

## column — 对齐成表格

```bash
column [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-t` | 按空白对齐成表格 |
| `-s 符` | 输入分隔符 |
| `-n` | 不对齐，按原样输出 |
| `-o 符` | 输出分隔符 |

```bash
$ column -t /etc/passwd                  # 7 列对齐，一眼看清
$ ps aux | column -t                     # 对齐进程列表
$ cat data.txt | column -t -s ,
$ cut -d: -f1,7 /etc/passwd | column -t  # 只要用户名和 shell
```

⚠️ **`column` 不加 `-t` 就是简单把行接起来**，不加参数没意义。

⚠️ **只适合展示**。对齐靠空格填充，**不能拿去当数据处理**。要按列操作必须回到 `awk`。

⚠️ `column` 不是 POSIX 标准命令，但几乎所有 Linux 都装了。`-t` 是 GNU 扩展。

## od / xxd — 看二进制

```bash
od [选项]... [文件]
xxd [选项]... [文件]
```

| 选项 | 作用 |
|---|---|
| `-c` | 字符显示（**最常用**） |
| `-A x` | 十六进制偏移地址（`-A d` 十进制，`-A o` 八进制） |
| `-t x1` | 每字节一列十六进制 |
| `-b` | 二进制 |

```bash
$ file mystery.bin
$ od -c mystery.bin              # 字符视图
$ od -An -t x1 mystery.bin       # 纯十六进制，不带地址
$ xxd mystery.bin | head         # xxd 更直观（vim 包自带）
$ od -A d -t u4 bigendian.bin    # 按 4 字节无符号整数看字节序
```

⚠️ **`od` 默认输出八进制**。想看字节序用 `-t x1` 或 `xxd`。

⚠️ **排查"为什么我的文件在别的机器上乱码"**靠它：文件头是 `FF FE` 就是 UTF-16LE，`EF BB BF` 就是带 BOM 的 UTF-8，`4C 6F` 就是 ASCII 的 `Lo`（错误地当成二进制传了）。

⚠️ `xxd` 属于 vim 包，不一定预装。`od` 一定有。

## iconv — 字符编码转换

```bash
iconv [选项]... 源 目标
iconv [选项]... -f 源编码 -t 目标编码 < 输入 > 输出
```

| 选项 | 作用 |
|---|---|
| `-f` | 源编码（from） |
| `-t` | 目标编码（to） |
| `-l` | 列出所有已知编码 |
| `-c` | 丢弃非法字符 |

```bash
$ iconv -l | grep -i utf             # 查编码名
$ iconv -f GBK -t UTF-8 input.txt > output.txt
$ iconv -f UTF-16LE -t UTF-8 file.dat > fixed.txt
$ iconv -f UTF-8 -t ASCII/ //TRANSLIT report.txt > ascii.txt
```

⚠️ **默认编码是当前 locale 的编码**，不写 `-f -t` 就是按 `LANG` 猜。要可重现就**显式写全**。

⚠️ **GBK 和 UTF-8 不是简单的一一映射**。GBK 转 UTF-8 一般没问题，但 UTF-8 转 GBK 遇到生僻字会失败或丢字。用 `//TRANSLIT` 转写或 `//IGNORE` 丢弃。

⚠️ **文件名乱码也要转**，光转内容不够。

⚠️ `iconv` 处理的是**字节流**，转完要检查有没有截断（转码失败时它可能输出半个字符）。

## diff — 比较差异

```bash
diff [选项]... 文件1 文件2
```

| 选项 | 作用 |
|---|---|
| `-u` | 统一格式（**最常用**），可直接 `patch` |
| `-r` | 递归比较目录 |
| `-q` | 只报「有差异」/「无差异」，不看内容 |
| `-i` | 忽略大小写 |
| `-w` | 忽略所有空白 |
| `-b` | 忽略空白变化量 |
| `--brief` | 同 `-q` |

```bash
$ diff -u old.conf new.conf
$ diff -q old.conf new.conf
$ diff -r dir1/ dir2/                 # 整个目录树
$ diff -w file1 file2                  # 忽略空白差异

# 生成补丁（这就是 diff 最主要的用途）
$ diff -u old.conf new.conf > fix.patch
$ patch old.conf < fix.patch            # 或 git apply
```

⚠️ **`diff` 的退出码有意义**：`0` = 一样，`1` = 有差异，`2` = 出错。脚本里 `diff` 做判断时不要直接 `if diff ...`，要判断退出码：

```bash
if diff -q a b >/dev/null; then echo "相同"; else echo "不同"; fi
```

⚠️ **默认输出格式不能直接 `patch`**。必须用 `-u` 或 `-c`。

⚠️ **`diff` 按行比较**，不比较二进制。需要 `cmp`。

⚠️ 有版本控制时**不要用 `diff` 做对比**，`git diff` 更好。

## seq — 生成数字序列

```bash
seq [选项]... 首 [步长] 末
```

| 用法 | 输出 |
|---|---|
| `seq 5` | 1 2 3 4 5 |
| `seq 2 2 8` | 2 4 6 8 |
| `seq -w 1 20` | 01 02 ... 20（等宽，**列对齐必备**） |
| `seq -s, 1 5` | 1,2,3,4,5 |
| `seq -f '%03g' 1 5` | 001 002 003 004 005 |
| `seq 0 0.5 2` | 0 0.5 1 1.5 2 |

```bash
# 批量建文件
$ for i in $(seq -w 1 20); do touch "file$i.txt"; done

# 逗号分隔，一行传给命令
$ seq -s, 1 5 | xargs -I{} echo "host{}"

# 生成表格行
$ seq -f 'user%02g\n' 1 5
```

⚠️ **`seq` 是 GNU coreutils 命令，不是 POSIX**，BSD/macOS 上可能没有。替代：`for ((i=1;i<=5;i++))`。

⚠️ **`seq` 输出每行一个**，不是空格分隔。要空格分隔用 `-s`。

⚠️ **`seq -w` 只在数字位数相同时才好看**。`seq -w 1 20` 对齐，`seq -w 1 1000` 就乱了。

## tee — 边输出边存盘

```bash
tee [选项]... [文件]...
```

| 选项 | 作用 |
|---|---|
| `-a` | **追加**，不覆盖 |
| `-i` | 忽略中断信号（SIGINT） |
| `-p` | 也写入非特权用户的管道（GNU） |

```bash
# 屏幕看得见，同时存一份
$ ./configure 2>&1 | tee config.log

# 追加到已有日志
$ dmesg | tee -a /var/log/dmesg.log

# 存但不显示（输出丢进 /dev/null）
$ some-command | tee /dev/null

# 存到需要 sudo 的位置
$ echo "net.ipv4.ip_forward=1" | sudo tee -a /etc/sysctl.d/99-custom.conf
```

⚠️ **最后那个 `sudo tee` 是 Linux 里的经典技巧**。`sudo echo ... > /etc/x` 不行，因为**重定向是调用你的 shell 做的，不是 sudo 那个 root 进程做的**，shell 没权限。`tee` 提权后才写。

⚠️ **`tee` 不加 `-a` 会覆盖文件**。反复追加日志一定要 `-a`。

⚠️ **`tee` 默认覆盖输出目标**。`cmd | tee f1 f2` 同时写两个文件，都是覆盖。

⚠️ **只写文件不看屏幕**用 `> file`，不要 `| tee file`（`tee` 会额外占一个进程，且不写 stdout 时要 `| tee file > /dev/null`）。

## xclip — 与剪贴板互通

```bash
xclip [选择器] [选项]... < 输入
```

| 选择器 | 用途 |
|---|---|
| `-selection clipboard` | 剪贴板（**默认**） |
| `-selection primary` | X 中键粘贴 |
| `-selection secondary` | 右键菜单 |
| `-o` / `-i` | 输出 / 读入（读入用 `-o`） |

```bash
$ echo "复制这段" | xclip -selection clipboard
$ xclip -selection clipboard -o > /tmp/pasted.txt

$ cat image.png | xclip -selection clipboard -t image/png

# 临时把远程文件复制到本地剪贴板
$ ssh user@host 'cat /remote/file.txt' | xclip -selection clipboard
```

⚠️ **服务器上没有 X11 剪贴板**。用 `xclip` 连不上会报 `Error: Can't open display:`。远程服务器上改用 `xsel`，或者干脆不用。

## man / apropos / whatis — 查手册（本手册的最后一站）

```bash
man [选项]... 名称
apropos [选项]... 关键词
whatis [选项]... 名称
```

| man 操作 | 作用 |
|---|---|
| `/关键词` | 手册内向下搜索 |
| `n` / `N` | 下一个 / 上一个匹配 |
| `q` | **退出** |
| `h` | 帮助 |
| `空格` / `b` | 下翻 / 上翻 |
| `G` / `g` | 到文件末尾 / 开头 |

| man 选项 | 作用 |
|---|---|
| **`-k 关键词`** | **按关键词搜索全部手册**（=`apropos`） |
| `-f 文件` | 查配置文件（`man fstab` 相当于 `man 5 fstab`） |
| `-w` | 只显示手册文件路径 |
| `-P pager` | 指定分页器 |
| `-C` | 显示中文翻译（需装语言包） |

```bash
$ man ls                      # 查命令
$ man 5 fstab                 # ⭐ 配置文件看第 5 章
$ man 8 useradd               # 系统管理命令看第 8 章
$ man 3 strlen                # C 库函数看第 3 章
$ man -k partition            # ⭐ 不知道命令名时按关键词搜
$ apropos disk usage
$ apropos --exact "ssh"
$ whatis ls
$ man -w ls                   # 只看文件在哪（不打开）
$ man sshd_config             # 通常会自动找到第 5 章
```

⚠️ **man 的章节号是硬要求**：`useradd` 在 8，`fstab` 在 5，`printf` 在 3。**记不住就 `apropos fstab`**。

⚠️ **`man` 里直接输入 `/` 搜索，不是 grep**。搜到结果按 `n` 跳下一个。

⚠️ **`man` 里忘了按 `q` 会让终端卡住**，看起来像挂了。

⚠️ **`man` 显示的是压缩过的手册**。要看未压缩源文件用 `zcat /usr/share/man/man1/ls.1.gz`。

⚠️ **手册只写「这命令怎么用」，不写「你的系统上是这样」**。本手册里凡是标了「以你的机器输出为准」的（版本号、unit 名、默认配置），最终仲裁都是 `man` + 上游文档。

---

⚠️ **`-selection clipboard` 要写全**。省略时默认就是它，但显式写清楚更不容易混。

⚠️ **命令行里传密码/密钥不要经过剪贴板**，会留在剪贴板历史里。

## 小结

| 场景 | 命令 |
|---|---|
| 看整个小文件 | `cat -n` |
| 看头/尾 | `head -n 20` / `tail -n 50` |
| 翻页看大文件 | `less -S` |
| 实时跟日志 | `sudo tail -F -v /var/log/syslog` |
| 数行数 | `wc -l` |
| 取某列 | `cut -d: -f1`（字段内无分隔符时）/ `awk -F: '{print $1}'` |
| 排序取最大 | `sort -h \| head` |
| 统计频次 Top N | `awk '{print $1}' f \| sort \| uniq -c \| sort -rn \| head` |
| 去重 | `sort -u`（**别单用 `uniq`**） |
| 大小写转换 | `tr 'a-z' 'A-Z'` |
| 去 Windows 换行 | `tr -d '\r'` |
| 表格对齐（仅显示） | `column -t` |
| 编码转换 | `iconv -f 源 -t 目标` |
| 比对两个文件 | `diff -u` |
| 边看边存 | `cmd 2>&1 \| tee log` |

**三条容易忘的规矩**

1. **`uniq` 前必须有 `sort`**，否则只去相邻重复。
2. **数字排序必须 `-n`**，否则 `10` 排在 `9` 前。
3. **Windows 来的一定先 `tr -d '\r'`**，否则搜不到东西。
